# 剧本到画面：显式调用行为验证

这九条测试检查显式启用 `zy-cinematic-realism` 后的文本行为。它们不测试自然语言能否自动选中 Skill，也不证明图像质量或创作提升。实际执行证据及完整响应保存在源码仓库的 `docs/behavior-check-v2.5.md`，不包含在 Skill 安装包内；其他功能的人工回归见 [Manual Regression Tests](manual-regression.md)。九条符合行为要求不代表静态检查或视觉验收通过。

## 执行方法与判定

显式调用本 Skill，读取 `SKILL.md` 及当前任务需要的引用文件，再发送下面的原始请求。每条按独立请求执行，不继承其他案例的场景、模型或已接受状态；S07 的全部修订背景已包含在请求中。执行时只提供请求与 Skill，不提供预期答案。保存完整响应后，再对照预期评阅，不改写实际输出。

- **pass**：满足该案例的主要范围、事实、状态及格式要求，没有与之冲突的新增行为。
- **partial**：主要任务成立，但有可指出的遗漏或含混，尚未违反核心事实或范围。
- **fail**：改动核心锁定事实、虚构缺失来源或结果、泄露尚未发生的认知，或明显违反请求范围与格式。

评阅必须检查完整动作、空间关系、来源覆盖和输出状态，不能仅凭某个词或标题出现判定。视觉可读性和物理关系在本组中只检查文字设计，实际图像执行需要另测。

## S01 — 短故事、明亮情绪与两个关键画面

原始请求：

```text
我有个短故事：父亲每天骑车送女儿上学，女儿总说自己已经长大了。这天父亲在校门外停下，第一次把车钥匙交给她，让她自己推车进门；父亲站在原地，女儿回头朝他笑。先帮我找到人物关系的变化，开发这个故事的视觉世界和两个关键画面，不要提示词。整体要明亮、有一点开心。
```

预期行为：

- 从交钥匙、独自推车与回头笑解释关系变化，不发明家庭前史或重大剧情。
- 提出服务于这一变化的空间、光线与材料选择，保留明亮、略开心的方向；新增选择作为提案，不冒充原文。
- 恰好两个关键画面，各有当前动作、视觉中心和选择理由；交钥匙与推车时手部占用可成立，车种可保留开放。
- 不输出提示词，不问生成模型。

## S02 — 仅关系与潜台词分析

原始请求：

```text
我写了一场戏：
内景，早餐店，早晨。姐姐把最后一个包子推给弟弟，说自己不饿。弟弟把它掰成两半，把较大的一半放回姐姐碗里。姐姐低头拿起筷子，没有说话。
只分析这两个人的关系和潜台词，简短一点。
```

预期行为：

- 简短解释让食物、分食物与沉默中的照料关系。
- 把姐姐是否真不饿、沉默的具体情绪等未明示内容保留为解释或歧义，不断言为事实。
- 只做所请求的分析，不加美术方向、关键画面、提示词或模式菜单。

## S03 — 缺少剧本正文

原始请求：

```text
我有一段剧本，想把它变成电影画面。你帮我看看怎么开始。
```

预期行为：

- 用普通语言请求剧本段落或梗概，可建议先提供一场戏。
- 不凭空发明场景，不要求先填专业表格，也不把生成模型问卷作为第一步。

## S04 — 单页不能决定整部电影的结局

原始请求：

```text
这是一部长片第12场的一页。我现在只能提供这一页：
夜，候车室。周宁靠近一名陌生人，把一张折起的纸递给他，说：按这个地址走。陌生人没有打开纸，只问：你会来吗？周宁摇头。
根据这一页，帮我判断整部电影的真正高潮和结局，并选出最后三个关键画面。
```

预期行为：

- 明确这页不足以支持全片高潮、结局或最后三个关键画面的确定判断。
- 可以提供有范围的本场分析，区分递纸、问句、摇头等事实与潜台词解释。
- 请求必要的后续故事覆盖；不虚构全片结局或把臆测的最终关键画面写成事实。

## S05 — 强烈导演语法服从已锁定的操作

原始请求：

```text
剧本是：维修员在工作台前，用右手把黄铜钥匙插进锁孔。室内唯一光源是原有顶灯。
按这个动作做一张真人电影单帧。机位固定在桌子正面，平视；右手、钥匙和锁孔必须清楚。强烈参考芬奇，但人物、动作、机位和唯一顶灯都锁定。只给一条中文模型中立 Prompt。
```

预期行为：

- 只输出一条中文模型中立提示词。
- 保留维修员、右手、黄铜钥匙正在插入、桌子正面平视与原有唯一顶灯，操作关系清楚。
- 导演语法落实为兼容的程序观察、空间组织和明暗控制，不增加灯具、不换机位，也不改成转钥匙或撤回钥匙。

## S06 — 忠实来源与改编要求冲突

原始请求：

```text
原剧本明确写的是：晴朗中午，女主在室外广场上接过奖杯，阳光直接照亮她和人群。
我要求完全忠于这一段的时间和天气，不允许改变任何剧情事实；同时，最终画面必须是凌晨雨夜。帮我开发这个关键画面。
```

预期行为：

- 指出晴朗中午与凌晨雨夜在时间、天气和光源上无法同时忠实保留。
- 问一个聚焦的取舍问题，或提出明确标记为改编的选项；不宣称两组要求已经同时满足。
- 不生成晴天中午兼雨夜的矛盾单帧。

## S07 — 修订依赖与交接状态

原始请求：

```text
这是剧本修订任务。旧版第一场：女主右手握红围巾走进厨房，第二场：她把围巾放在餐桌上。新版改为第一场左手握一封信进厨房，第二场把信放在餐桌上。两版其余内容相同。
已经接受的设计：白天、自然窗光、朴素明亮的厨房、蓝色工作服。此前助手提出过黄色钨丝灯和红裙，但我没有接受。
请简短说明两个画面的修改影响，并整理一张交接卡。只有旧版提示词，没有生成图片。
```

预期行为：

- 两场都依赖新版：第一场左手持信，第二场同一封信落到餐桌；同步处理道具与手部状态，不凭空换手或复制信。
- 保留已接受的白天、窗光、厨房与蓝色工作服；黄色灯光与红裙仍为未接受提案。
- 交接卡说明所读材料的范围与缺口，准确记录只有旧提示词、没有生成图；不声称已修复、检查或批准图片。

## S08 — 观众与人物知道的内容不同

原始请求：

```text
我的故事有三场，按顺序给你：
1. 老人趁孩子不在，把一把钥匙藏到厨房桌底。观众看见了这个动作。
2. 孩子进来问钥匙在哪，老人摇头。孩子还不知道钥匙的位置。
3. 老人出门后，孩子弯腰捡铅笔，才发现桌底的钥匙。
帮我开发三个关键画面和共同的视觉规则，先不要 Prompt。不要让第二场提前揭露孩子知道钥匙在哪里。
```

预期行为：

- 只据三场文字开发三个关键画面及共同规则，不引入后续事件。
- 第一场观众知道、第二场孩子不知道、第三场孩子才发现；第二场不能用视线或动作提前泄露孩子知情。
- 跨场保持同一钥匙位置和厨房空间；未提供的光线、藏法与地理选择标记为视觉提案。
- 不输出提示词。

## S09 — 文本指定的剪纸拼贴媒介

原始请求：

```text
一段童话：纸做的小狐狸把一片叶子举在头顶，跑过雨中的纸桥，桥另一端的纸兔子撑着一把小伞等它。
做成一张剪纸拼贴插画，保留纸边、折痕和手工搭建感。只给中文模型中立 Prompt。
```

预期行为：

- 只输出中文模型中立提示词，保留狐狸举叶跑过雨中纸桥、另一端兔子撑伞等待的动作与空间关系。
- 用剪纸边缘、折痕、纸层与手工搭建表现画面，不强制改成真人摄影或写实毛发。
- 无实际参考图片时，不声称检查了图片或观察到 Dream Decode 的 Expression Mechanism。
