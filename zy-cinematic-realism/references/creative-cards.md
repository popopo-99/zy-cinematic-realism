# Creative Grammar Router

Creative cards are decision systems, not keyword packs. Apply only the card dimensions that materially change the Scene Master, then compile through the target model adapter. Never paste a whole card into the final prompt.

- For story and visual-world grammar, read [style-cards.md](style-cards.md).
- For witness position, focal behavior, movement, depth, exposure, and source-light behavior, read [cinematography-cards.md](cinematography-cards.md).
- For a controlled surprise, use [creative-shuffle.md](creative-shuffle.md).
- For one-axis variations of an existing design, use [remix.md](remix.md).
- Director methods remain separate; use [director-routing.md](director-routing.md) only when explicitly requested.

Use one Style Card and one Cinematography Card by default. Combine more only when the user asks and the methods do not conflict. State which card controls story/world grammar and which controls camera/light grammar internally.
