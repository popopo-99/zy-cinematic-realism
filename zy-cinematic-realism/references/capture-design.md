# 摄影设计与器材选择

## 使用范围

在用户提出摄影机、镜头、焦段、景深、成像介质、滤镜、经典电影摄影参考，或需要把口语化观看感受转成摄影决策时使用。普通场景直接补齐必要的摄影选择。器材浏览、型号比较、冷门器材和特殊光学效果按需查阅[器材武器库](equipment-library.md)。电影、导演、摄影师和经典镜头参考按需查阅[电影摄影参考库](cinema-shot-library.md)。

本功能吸收 Jury 粉丝版的器材视觉签名、成像方案和结构化摄影字段思路，扩展为造梦师统一的摄影设计能力。摄影选择写入现有 Scene Master 的 `Camera / Viewpoint`，与 `Light / Value`、`Surface / Rendering` 协同。Scene Master 持续保存当前场景的有效决策。

摄影设计服务于故事、空间、观看位置与画面效果。插画、绘画、版画等非摄影媒介沿用其制作逻辑，真实器材的引入依据用户明确要求的摄影化或写实改编范围。实物木偶、黏土和微缩定格可原生使用相机、微距、景深与灯光，同时保留其材质和制作尺度。数字模拟的定格风格按授权参考的实际媒介处理。

## 统一入口

根据用户提供的信息深度调整沟通方式，无需让用户先选择专业程度。

| 用户表达 | 执行方式 |
| --- | --- |
| “给我写一个树林人像的提示词” | 依据场景补齐必要选择，直接输出可复制的普通文本 |
| “像站在他旁边，背景还能看清” | 先确定观看距离、人物占比和背景可读性，再选择支持这些结果的焦段、光圈与对焦方案 |
| “Sony α7 IV，Helios 44-2，f/2” | 保留指定设备与参数，在开放的机位、距离、背景条件中完成画面设计 |
| “给我看看有什么镜头可以选” | 展示少量相关器材及其可见效果、适用条件，允许继续查看或比较 |
| “像某导演某部电影” | 确认用户要借用的画面特征，按需查询摄影资料和镜头上下文，记录来源与可迁移范围 |
| “你决定”“直接出词” | 自行完成未指定项并生成文本提示词 |

只为真正影响结果的未解决冲突或无法替代的缺失输入提问。对可合理决定的空白直接给出方案。用户需要引导时，围绕一项可见差异给出口语化选择，例如“你更希望像站在人物身边，还是像隔着一段距离观察？”回答后完成参数映射。

用户只要提示词时，直接交付提示词。用户要看方案、器材解释或比较时，再展示相应信息。内部摄影记录和资料核验过程按需提供。

用户要求“先做 Plan，确认后再写”或“按 Jury 手册完整流程”时，按[引导工作流](guided-capture-workflow.md)展示同一记录的可审阅方案。修改沿用最新有效方案，明确接受的可见选择按其范围保护。未展示参数继续保持原有状态。接受后编译所请求的普通文本或 JSON；明确直接输出的请求立即进入编译。

## 摄影生成策略选择 / Capture Strategy Selection

在现有摄影记录的决策来源、锁定状态与适用范围中记录当前生成路径及依据。结合输入是否存在、变化范围和用户接受范围选择文生图或单图编辑。

| 当前任务 | 策略判断 |
| --- | --- |
| 无参考图的原创摄影画面 | 采用文生图，补齐能表现摄影目标的场景与OPEN选择 |
| 现有图的景深、对焦、眩光等摄影修改 | 优先评估单图编辑，定位变化区域并继承已接受内容 |
| 现有图的强鱼眼、极端透视等整体投影变化 | 评估所需几何变化与保留范围，先处理实际取舍再编译 |

整体投影变化需分别核对人物与建筑身份、真实场景的连接与遮挡拓扑、摄影机观察位置，以及画面中的像素坐标与投影位置。身份、拓扑和机位的保留可以允许外围像点随投影移动。把相应移动写入允许变化范围，防止含混的“位置不变”压制用户已要求的曲率。

对同时要求保真与大幅投影变化的请求，简短说明编辑有利于延续人物和场景，强几何变化可能受到保留约束或模型执行能力影响。用户需要实际取舍时，提供明确选择，例如继续同图编辑并接受其可能的曲率限制，或经用户授权释放具体保留项后重新生成。重新生成沿用仍有效的锁定，实际身份与布局延续程度按结果核查。

这段说明用于帮助用户理解本次保留边界，与后续直接编译可以在同一答复中完成。用户已经明确合理路径、保留项和投影移动范围，并且只要提示词时，把这些边界写进编辑载荷即可。

只在需要释放锁定或存在未解决的实际冲突时请求用户决定。用户已指定合理路径与允许变化范围时直接编译。用户明确锁定原图时，在其授权范围内推进编辑，受限目标据实说明。一次成功或失败的案例只支持其实际条件下的观察，鱼眼编辑与文生图均按当前任务评估。

策略选择沿用同一Scene Master、Capture Design、参考职责与连续性规则。Plan审阅、用户直接出词、专业参数保留和跨模型转换各按已有合约执行。

## 从观看目标到摄影选择

依次解决画面需要表达什么、观看者站在哪里、哪些层面必须清楚、背景与主体如何分离，再补齐器材与效果。顺序可随输入调整，已有明确选择直接保留。

| 口语目标 | 需要落实的画面关系 | 可选择的摄影手段 |
| --- | --- | --- |
| “像我就站在他身边” | 近距离观看、明确的空间邻近关系、自然的人物比例 | 合适的机位距离和中广角或标准视角，保持脸部距离与构图相容 |
| “背景别太虚，要知道他在哪里” | 环境、人物与故事线索同时可读 | 增加有效景深，调整光圈、机位、对焦位置或主体背景间距 |
| “只想注意到他的眼神” | 眼睛成为清晰中心，其他细节适度退让 | 眼睛对焦、合适的景别、景深与背景亮度关系 |
| “人和后面的山像挨在一起” | 在指定人物占比下，远景显得更大、前后距离感减弱 | 增加摄影机到人物的距离，并用较长焦段维持人物占比 |
| “有点老电影的感觉” | 先落实年代感、色彩、反差、颗粒或高光行为中真正需要的部分 | 选择有目标的介质与色彩处理，必要时用一项口语问题确认方向 |
| “背景绕着人轻轻转” | 中心清晰、外围失焦形状呈环绕趋势 | 合适的旋焦镜头特征、开放光圈、背景纹理与距离分离 |

转换口语时保留用户原本要求的主体、动作、场景、时间和光源。设备选择不能凭空改变故事事实。

## 摄影语言归一

遇到摄影术语、中文“镜头”的多义表达，或随时间变化的运镜与对焦要求时，先按需查阅[摄影语言索引](camera-language-dictionary.md)和对应条目。先确定用户希望看见的结果，再将镜头光学、景别、机位高度与朝向、移动、清晰关系分别落入现有 `Camera / Viewpoint` 与 Capture Design。词典只提供含义、边界和检索入口。

日常说法与专业参数沿用上面的统一入口。明确指定的机身、实际焦距、f/T值、有效画幅模式和运动意图保留其原值与范围，缺少的选择按场景补齐。口语提问优先说明可见变化与推荐原因。简短解释只取回答当前问题所需的条件，用户要求专业定义时再展开原理、有效画幅和适用边界。词典的完整字段供按需检索，回答长度随请求决定。直接出词的请求沿用普通文本合约。

按索引的呈现方式区分单帧可见结果、动作线索和连续过程。静态图像编译使用当前一帧的机位、构图与清晰状态，时间过程按[编译边界](prompt-compiler.md#still-and-temporal-camera-language)处理。非摄影媒介中的鱼眼等要求按其投影、构图和制作逻辑解释。

## 摄影记录

在 `Camera / Viewpoint` 内按需要记录下列决策。光源继续由 `Light / Value` 的 Source Light Map 管理，介质、颗粒与最终表面表现继续由 `Surface / Rendering` 管理。交叉引用相应决策即可。

| 项目 | 记录内容 |
| --- | --- |
| 观看目标 | 用户希望产生的观看感受和必须可见的效果 |
| 摄影机与有效画幅 | 指定机身、拍摄模式或已知有效成像区域，必要时记录裁切 |
| 镜头 | 型号或镜头系列、定焦或变焦、球面或变形宽银幕、实际焦距 |
| 等效视角 | 仅在参考画幅与裁切关系已知时记录等效焦距，并标明等效所依据的格式 |
| 机位 | 距离、高度、朝向、观看侧、俯仰与人物占比 |
| 清晰关系 | 光圈写法、对焦目标、必须清晰的平面与允许失焦的区域 |
| 光学表现 | 所需效果、强度、支持条件与作用范围 |
| 滤镜与介质 | 扩散滤镜、胶片或数字基础、颗粒、高光响应及色彩处理 |
| 决策来源 | 用户指定、授权参考或资料依据、系统补齐 |
| 锁定状态 | 用户明确指定或具体采纳的字段按范围记为 `USER-LOCKED`，其余系统候选为 `OPEN` |
| 接受状态 | 候选或已接受，并记录用户实际认可的字段或外观范围。图像生成、检查与认可状态另行记录 |
| 适用范围 | 项目共同设定、角色资产、当前镜头或局部修改 |

摄影记录随任务规模裁剪。一个普通树林人像通常只需观看位置、焦段或视角、清晰关系、现有光源和一项必要的成像特征。

### 决策优先级

沿用编译器的 `USER-LOCKED > reference-derived Hybrid Decision > system-generated default`。授权参考仅在指定的参考职责和迁移范围内影响 OPEN 选择。显式来源文档的有效要求同样保留其授权范围。

用户指定的器材、焦距、光圈、机位或效果应保持可追溯。存在真实矛盾时，先尝试在开放项中解决。例如保留大光圈，通过主体站位和对焦面让双人眼睛清楚。全部相关项都已锁定且无法同时满足时，用一个问题指出需要调整的决策。通过确认后更新有效状态。

系统确定一个候选方案后即可继续编译。来源、锁定、接受状态和范围分别记录。用户说“就用 58mm”时，该字段成为相应范围的 USER-LOCKED；仅说“这张图不错”时，按实际认可的外观范围记录接受状态，内部未展示的器材参数继续保持原状态。系统候选的生成本身不代表用户接受。

## 摄影一致性

### 视角与距离

透视取决于摄影机位置和到主体的距离。焦距在同一有效画幅上改变取景范围。要表达远近压缩、贴近观看或面部透视变化，应同时写清机位距离与构图关系。

实际焦距与等效视角分别记录。传感器或胶片格式、裁切模式未知时，可直接描述所需视角和画面关系。交付画幅如 16:9、21:9、竖幅 4:5 单独属于 Delivery，推算视角需要有效成像区域和裁切依据。

摄影镜头的 f 值与电影镜头的 T 值保留原有写法。T 值主要描述通光量，景深描述还需考虑镜头与拍摄条件。缺乏依据时，以需要清楚的范围描述结果。

### 景深与对焦

把主体距离、焦距、光圈、人物前后位置与必须清晰的平面一起考虑。眼睛、两个人的脸、手中物件、远处线索等要求需能在同一方案中成立。若需要极浅景深，让焦点有明确落点，并说明哪些区域允许失焦。

为背景虚化安排合理的主体背景分离。用户锁定了现有空间时，在该空间允许的范围内选取镜头与机位。人物脸部、身体比例和树干几何等需要稳定的结构应保持自然。

### 特殊效果与条件

| 效果 | 所需条件与编译重点 |
| --- | --- |
| 旋焦 | 明确中心清晰与外围失焦范围，利用具有相关光学特征的镜头、足够的主体背景分离和背景细碎纹理。强度随具体镜头、光圈和画幅变化 |
| 猫眼光斑 | 画面边缘失焦高光的形状变化，依赖镜头、视场位置和光圈。保留实际存在的背景亮点 |
| 变形宽银幕特征 | 按镜头系列和场景选择椭圆焦外、水平眩光或边缘行为。存在相应光源与几何条件时表达其结果 |
| 镜头眩光 | 与进入镜头的强光方向、位置和镜头特征关联，保留光源动机 |
| 扩散滤镜 | 用滤镜强度、高光扩散和局部反差变化描述，关注面部和细节仍需保留的范围 |
| 胶片卤光 | 在合适高光边界描述介质响应，注明需要的范围与强度 |
| 雾或大气散射 | 由场景天气、空间与光线传播决定，遵循现有天气设定 |

分别处理镜头眩光、滤镜扩散、胶片卤光与天气散射。仅添加用户需要且有条件支撑的效果。效果条件不足时，优先调整 OPEN 机位、距离、光圈或背景选择。新增灯光、烟雾、天气或环境结构需要来自用户要求或已有场景授权。

机身品牌用于保留器材选择和有依据的成像语境。最终色彩、颗粒、反差、高光与光学效果分别描述。设备型号的出现本身无法保证模型呈现出对应特征。

## 器材与电影参考

专业用户可直接点名型号、镜头系列、焦距、光圈、滤镜和成像介质。缺乏具体型号信息时保留用户原话，并以可见效果完成其余 OPEN 决策。来源核验和器材替代建议可在用户提出浏览、比较或考证时提供。

浏览武器库时优先展示与当前目标相关的少量条目。每项说明可见差异、适用条件、可直接使用的表达和已核实的来源状态。用户可以继续要求扩展型号范围。

电影参考分清作品层面的摄影配置、某段落的摄影语言、某个具体镜头的器材与机位。片单与作品器材记录可提供候选方向，具体镜头的断言需要对应证据。资料尚未支持的焦距、光圈、滤镜和镜头型号保持未确认状态。

从影片迁移时只带入用户授权的摄影行为。人物身份、演员面孔、服装、道具、剧情和标志性场景需要独立授权。用户需要某种观看体验时，将其转换成当前场景可执行的机位、层次、光线和成像关系。

术语条目的关联ID用于按需进入已有卡片。例如“《1917》德军地下空间用了什么镜头”直接读取[德军地下空间场景卡](cinema-shot-library.md#shot-1917-basement)，按其场景实参与未知项回答。关联卡仍保留原来的制作、段落或画面证据范围。

检索按当前问题走到需要的一层。解释概念时读取词典的原理与条件、可见结果；选器材时沿 `related_equipment_ids` 核对适用条件；找影片方法时沿 `related_film_card_ids` 核对作品、场景和来源范围，最后用“迁移方法”回写本摄影记录。关联数组为空时保留资料缺口，可继续提供有依据的通用方法。器材边与电影边分别成立，两边同时出现须有独立制作证据才能断言该器材用于该片。

导演与摄影指导姓名先定位各自在某部作品中的职务，再查询其作品或场景记录。关于长期器材习惯的判断需要多部作品的直接依据和明确的样本范围。仅有单片资料时回答该片实例。参考图可支持画面观察，器材历史身份需有制作来源。证据类型与记录规则见[电影库](cinema-shot-library.md#证据类型与事实范围)。

## 普通文本编译

按场景需要组合主体与动作、空间与构图、观看位置、清晰关系、现有光线、必要的器材特征、介质及排除项。段落数量由内容决定。

明确器材名称时可保留型号和参数，同时写出用户真正需要看到的画面结果。例如指定 Helios 后仍应表达眼睛清晰、外围树叶失焦并呈轻微环绕趋势。针对模型容易误读的关键效果，用少量准确英文词辅助即可。

摄影事实在不同模型之间保持一致，文本长度、顺序、参数表达按目标模型适配。普通文本默认使用用户交流的语言。编译后的文本只保留有助于生成的内容，核验说明、来源分级、锁定标记与内部推导按用户需要单独提供。

### 可选 JSON

只有用户明确需要结构化交付时才导出 JSON。用户已有 schema 时沿用该 schema。需要新结构时，可在当前场景结构中增加精简的 `capture` 对象，或采用用户认可的现有结构。按任务提供必要字段，颜色数量依据画面需求确定。

明确选择 Jury JSON Brief 时使用[已核对的静帧结构](jury-json-brief.md)，其 12–15 色约束只作用于该格式。Jury 旧手册里的资料文件名和五栏信息按[迁移表](guided-capture-workflow.md#旧手册引用与五栏信息迁移)进入现有器材库、电影库、词典与项目结果记录。

普通文本与 JSON 从同一个当前 Scene Master 导出，摄影选择保持一致。资料来源和研究说明通常放在生成载荷之外，用户要求嵌入时再安排相应字段。

## 修改、系列与跨模型

文字修改以当前有效 Scene Master 为基础，累计保留用户指令和已接受的修改。尚未回评的当前候选继续有效，并保留其候选状态。图像修改以用户本轮指定的图或最近实际待修改图为底图，首张失败图也可以直接修复；此前已接受的特征作为保留约束。用户说“背景少虚一点”时，更新清晰关系并同步有依赖的开放参数。用户明确要求更换器材或推翻前一方案时，更新相应锁定项。

系列可共享机身、镜头系列、介质、色彩与滤镜风格。每个镜头的焦段、机位、景别和对焦按叙事需要决定，用户锁定的系列参数继续继承。共享状态与镜头局部变化分别记录，避免局部修改扩散到整个系列。

角色、服装、道具和场景参考资产优先确保身份、比例、材料和结构可识别，按[参考资产包](asset-pack.md)管理其职责。最终镜头的强烈失焦、旋焦、低照度或眩光只在该资产明确需要展示这些效果时采用。

切换模型时保存当前已经解析的机位、焦段或视角、景深、焦点、光学效果、介质和既有场景事实，其中也包括正在使用的 OPEN 候选值。转码期间沿用这些值，保留来源、锁定和接受状态，按目标模型调整表达。目标模型跟随不足时，依据实际结果修复有效提示词，保留用户指定的摄影目标。

新独立项目从当前用户输入建立状态。用户需要跨对话延续时，提供可复制的项目交接摘要，包含当前有效摄影记录、已锁定与 OPEN 选择、各自接受状态、参考来源、当前有效修改与适用范围。

## 使用示例

以下示例说明处理方式，可随实际场景调整。

### 例一　树林旋焦，直接出词

用户提出“白天树林人物，背景轻微旋焦，其他你决定”。可选标准视角的中近景与具有旋焦特征的镜头，安排眼睛对焦、人物与树叶背景分离、外围失焦纹理轻微环绕。若当前场景已有日光与天空光，沿用该光源组合。直接输出普通文本。

### 例二　口语描述环境可读性

用户提出“人物要清楚，也要看得见后面的店铺”。把两者转成必须可读的平面，选择能支持它们的焦段、距离和景深。提示词说明人物与店铺的相对位置及清晰关系。器材型号按任务需要决定。

### 例三　专业用户指定设备

用户提出“Alexa 35，Cooke S4/i 50mm，T2.8，室内双人对话”。保留机身、镜头与通光设定，在开放机位和演员站位中安排双人清晰关系。对有效画幅与裁切缺乏信息时，保留实际焦距并描述所需取景关系。

### 例四　浏览武器库

用户提出“我想拍有距离感的城市人物，给我几个镜头方向”。从相关器材条目中选取少量有差异的方案，说明观看距离、人物占比、背景尺度与焦外表现。用户选中方向后，完成其余 OPEN 选择并生成提示词。

### 例五　借用经典电影摄影

用户提出“想借用某电影里两个人在餐桌前对峙的感觉”。从用户指向的段落或实际参考中确认观看位置、人物关系与光线，查询需要的摄影依据。将这些特征应用到用户当前人物和场景。具体器材尚无证据时，以可见画面关系完成方案。

### 例六　保留已选参数并解决冲突

用户要求“大光圈，两个人眼睛都清楚”。优先在 OPEN 站位、机位和对焦面中完成要求。若用户又锁定两个人相距很远的前后位置、最近对焦距离与极浅景深，则用一个问题确认需要优先保留的清晰目标或可调整参数。

### 例七　Seedream 5.5 转到其他模型

已接受的方案包含眼平机位、58mm、眼睛对焦、外围轻微旋焦和自然日光。转码时保留这些选择，按新模型语法调整文本和可用控制。当前镜头的旋焦范围继续由共享摄影记录提供。

### 例八　角色资产与最终镜头

用户先制作人物身份参考，再制作树林旋焦镜头。身份参考采用足以看清面部、发型和服装结构的成像方案。最终镜头继承人物身份，并使用该镜头需要的景深、背景距离和旋焦强度。

## 媒介适配与虚拟摄影

写实CG和风格化三维可在同一 `Camera / Viewpoint` 中使用虚拟视点、等效视角、景深和有明确用途的机身或镜头参照。按来源记录用户给定的虚拟参照与OPEN创作选择，具体数值的必要性仍由取景和清晰目标决定。器材名称表达创作方向，实际设备模拟准确性需要独立成像证据。

三渲二优先描述造型、明暗分组、视点和材质简化，保留有用且已授权的虚拟光学。平面和绘画媒介使用绘画空间、轮廓、笔触与边缘控制。无关的实体设备字段转为视觉功能描述，结构化输出中可说明不适用原因。摄影、虚拟摄影与绘画观看逻辑共同沿用现有参考职责、锁定及摄影生成策略。
