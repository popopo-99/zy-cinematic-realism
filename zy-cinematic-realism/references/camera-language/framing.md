# 景别与取景

按[词典索引](../camera-language-dictionary.md)读取所需条目。景别由画框中的主体占比和裁切确定，焦距与机位距离用于实现它。中文景别分法与英文制作惯例存在差异，明确身体裁切和环境需求优先于名称。以下均可用于静帧或视频的某一时刻，景别随时间变化时还需另记运动或变焦过程。

<a id="term-extreme-long-shot"></a>
### 极远景 / Extreme Long Shot

- **分类** Framing & Shot Size
- **常用别名** `["大远景", "大全景", "ELS", "Extreme Wide Shot", "EWS"]`
- **通俗说法** 环境占据绝大部分画面，人小得像环境里的一个点。
- **专业定义** 以宏观空间为主要信息、主体占比较小的景别，用于建立地理尺度、环境关系或人物处境。具体占比随主体尺寸、画幅和叙事目标确定。
- **原理与条件** 人物、地形与画框的相对尺度决定效果，观看距离和视角共同服务于取景。服装对比、轮廓和行动方向影响微小人物的可辨认性。
- **可见结果** 静帧可观察环境压倒性的尺度与人物位置，脸部细节通常不足以成为主要信息。序列中的建立与转场作用需结合前后镜头判断。
- **典型场景** 荒漠旅人、巨大建筑中的孤独人物、地理关系建立、灾难或气候压力的视觉呈现。
- **常见误解** 极远景可以由多种焦距与距离实现。建立镜头是叙事功能，具体景别须依需要建立的信息选择。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `观看目标`的尺度感、`机位`的人物占比与观看距离、`镜头`的所需视角，并协调 Camera / Viewpoint 的构图。
- **迁移方法** 先标清人物在环境中的位置和移动方向，再决定地面、天空与建筑的比例。需要脸部信息时另选相邻景别或其他镜头。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["shot-dune-desert"]` [沙漠场景卡](../cinema-shot-library.md#shot-dune-desert)提供环境尺度的创作迁移条件，各单镜头人物比例和焦距未知。

<a id="term-long-shot"></a>
### 全景 / Long Shot

- **分类** Framing & Shot Size
- **常用别名** `["全身景", "LS", "Full Shot", "Wide Shot", "远景"]`
- **通俗说法** 看得见人物从头到脚，也能知道他站在什么地方。
- **专业定义** 常见英文人物景别用法中，Long Shot 通常容纳全身并保留周围环境。中文“远景”有更强调环境的用法，执行时应明确全身边界和主体占比。
- **原理与条件** 全身动作、脚下接触关系和环境留量共同决定构图，适用焦距随有效画幅与拍摄距离变化。
- **可见结果** 静帧可读全身姿态、站位和所在空间。前后画面是否构成建立或动作连续关系，需按序列判断。
- **典型场景** 人物进入场所、双人站位、服装与动作展示、人物与地面障碍的关系。
- **常见误解** Wide Shot 在制作现场也常作为宽景的概称，范围可能跨越多种中文景别。用户已经指定全身与环境比例时，按具体边界执行。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的主体占比与距离、`镜头`的视角、`清晰关系`的人物和环境可读性。
- **迁移方法** 明确头顶与脚下留量、主体位置和必须保留的场景线索，再安排适当机位与焦距，静帧保留当前全身状态。

<a id="term-medium-shot"></a>
### 中景 / Medium Shot

- **分类** Framing & Shot Size
- **常用别名** `["MS", "Waist Shot", "腰部以上景别"]`
- **通俗说法** 大约拍到腰部，能同时看表情和手上的动作。
- **专业定义** 人物通常以腰部附近至头顶的裁切呈现的景别，结合表情、上身姿态和有限环境信息。实际裁切可依动作与画幅调整。
- **原理与条件** 裁切位置、手部活动范围和人物站位决定叙事信息，机位距离与焦距共同形成所需占比。
- **可见结果** 静帧中面部、上身动作和周围线索共同可读，单张画面仅呈现动作的当前状态。连续动作与切换节奏需时间序列。
- **典型场景** 双人交谈、递交物件、桌边动作、表情与身体语言同等重要的场面。
- **常见误解** “中景”描述裁切范围，具体焦距和摄影机高度另定。人物坐姿或宽银幕构图下，需直接注明要保留的身体与道具。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的距离与人物占比、`观看目标`的动作信息、`清晰关系`的脸部和手中物件。
- **迁移方法** 先保留需要读清的手势与道具，再确定腰部附近裁切及环境留量，在当前场景内完成机位和焦距选择。

<a id="term-medium-close-up"></a>
### 中近景 / Medium Close-up

- **分类** Framing & Shot Size
- **常用别名** `["MCU", "胸像景别", "胸部以上景别"]`
- **通俗说法** 大约拍到胸口，把注意力放在表情上，还能看到肩膀姿态。
- **专业定义** 常以胸部附近至头顶为边界的人物景别，介于中景与脸部特写之间。中文“近景”的具体裁切需按用户语境确认。
- **原理与条件** 脸部占比、双肩与头顶留量共同决定亲近程度，机位距离影响面部透视，焦距负责配合有效画幅完成取景。
- **可见结果** 静帧突出眼神、表情与肩颈姿态，同时留有少量空间线索。对话节奏和反应变化需要连续画面。
- **典型场景** 对话、聆听反应、身份清楚的环境人像、保留服装上身细节的情绪画面。
- **常见误解** 中近景无需固定焦距。浅景深须单独规定，越肩关系也须单独安排，头肩与胸口的裁切以具体描述为准。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的距离与人物占比、`清晰关系`的眼睛和肩部范围、`镜头`的视角。
- **迁移方法** 保留头顶、双肩和胸部附近的明确边界，按所需观看距离决定面部透视，背景可读性单独写清。

<a id="term-close-up"></a>
### 特写 / Close-up

- **分类** Framing & Shot Size
- **常用别名** `["CU", "近特写", "脸部特写"]`
- **通俗说法** 让脸、手或关键物件占据主要画面。
- **专业定义** 以主体或叙事细节在画面中的占比和裁切界定的景别。人物特写通常突出脸部，具体边界随语境和交付画幅确定。
- **原理与条件** 裁切、视觉中心、观看距离与清晰落点共同决定注意力。选用焦距还需结合有效画幅、最短对焦能力与所需面部比例。
- **可见结果** 静帧可直接观察细节占据画面，环境信息减少，表情或物件成为注意中心。情绪转变与动作前后关系需要序列。
- **典型场景** 关键眼神、手指动作、传递剧情信息的物件、对话中的反应。
- **常见误解** 特写可由不同焦距和距离实现。近摄与微距还涉及对焦距离及放大倍率，拍摄普通人脸特写时按所需比例选择方案。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `观看目标`的视觉中心、`机位`的裁切与主体占比、`清晰关系`的对焦目标、`镜头`的焦距。
- **迁移方法** 先决定脸部、手部或物件中必须保留的区域，再选择观看距离和对焦落点。越肩关系可与特写组合，原场景事实继续继承。

<a id="term-extreme-close-up"></a>
### 大特写 / Extreme Close-up

- **分类** Framing & Shot Size
- **常用别名** `["极特写", "ECU", "XCU", "局部大特写"]`
- **通俗说法** 只看眼睛、嘴角、指尖或一个很小的关键细节。
- **专业定义** 将主体的局部细节放大到占据画面主要区域的景别，裁切通常超出常规完整脸部或物件边界。其叙事作用由被选细节和上下文决定。
- **原理与条件** 细节尺寸、拍摄倍率、镜头对焦能力和景深共同影响可读性，微小主体可能需要微距能力，较大主体局部可用普通近摄完成。
- **可见结果** 静帧强化局部纹理和微小表情，整体空间线索有限。作为揭示或插入镜头的作用还需前后画面，单帧只显示该细节。
- **典型场景** 瞳孔与泪水、扣动扳机的手指、刻字、细小机械动作、触觉性材料表现。
- **常见误解** 大特写描述画框中的局部占比，微距描述成像倍率与拍摄尺度。过浅景深可能损失关键线索，需明确必须清楚的细节。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的裁切与距离、`清晰关系`的局部平面、`镜头`的近摄条件、`观看目标`的叙事细节。
- **迁移方法** 明确要显示的局部及其范围，保留该细节所需的形状、纹理和动作状态，再决定倍率与清晰范围。

- **related_film_card_ids** `[]`

<a id="term-cowboy-shot"></a>
### 牛仔景别 / Cowboy Shot

- **分类** Framing & Shot Size
- **常用别名** `["美国景", "American Shot", "Plan Américain", "大腿以上景别"]`
- **通俗说法** 大约从大腿或膝盖上方拍到头顶，脸和腰间动作都能看见。
- **专业定义** 常将人物裁切在大腿至膝上附近的中远人物景别，历史语境常与西部片中腰间枪套和拔枪动作的可见性相关。具体边界依动作要求确定。
- **原理与条件** 面部、手部、腰侧道具和身体姿态共同形成视觉信息，构图需留出动作空间，焦距和距离按场景选择。
- **可见结果** 静帧同时显示人物表情与腰侧动作准备，连续拔枪、行走或对峙节奏需要时间序列。
- **典型场景** 站立对峙、腰间道具、人物即将行动的准备姿态，也可用于其他类型的人物场面。
- **常见误解** 名称来自类型片惯例，角色服装与剧情仍由当前场景决定。裁切到大腿附近的要求与某一固定焦距或仰拍角度无绑定关系。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的裁切与人物占比、`观看目标`的动作信息、`清晰关系`的脸部与腰侧道具。
- **迁移方法** 按现有人物与道具，明确大腿或膝上的裁切位置、手部动作范围及头顶留量，再安排机位与视角。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `[]`
