# 构图与空间组织

从[摄影语言索引](../camera-language-dictionary.md)进入。构图以主体、环境和观看位置的实际关系表达，沿用唯一 Scene Master 的构图与连续性。非摄影媒介按其自身空间组织解释。

<a id="term-centered"></a>
### 中心构图 / Centered Composition

- **分类** Composition
- **常用别名** `["中心构图", "居中构图", "主体居中", "centered composition", "central framing"]`
- **通俗说法** 把最重要的人或物放在画面中央，让视线直接落过去。
- **专业定义** 将主要主体或视觉中心组织在画框中心区域的构图方法，主体占比、背景结构与边缘信息共同决定平衡。
- **原理与条件** 位置、亮度、色彩、清晰度和线条共同引导注意，中心位置只是其中一个因素。对称关系需另行指定。
- **可见结果** 单帧可直接看到主体居中，背景与留白可进一步形成稳定、压迫或孤立等语境相关效果。
- **典型场景** 正面人物、仪式性空间、需要明确视觉中心的画面。
- **常见误解** 中心构图可与不对称背景共存。严格几何对称需要另设两侧形状、距离和视点关系，情绪含义随场景变化。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `观看目标`记录视觉中心和主体占比，`机位`记录观看位置与中心关系，构图继续写入 Camera / Viewpoint。
- **迁移方法** 指明哪个主体居中、占多大画面以及需要保留的背景。视频中若持续居中，另描述跟随或调度方式和时间范围。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["film-batman-2022"]` [影片记录](../cinema-shot-library.md#film-batman-2022)提供中央叙事区与边缘成像参与设计的制作范围说明，逐镜头构图仍需实际画面。

<a id="term-negative-space"></a>
### 负空间 / Negative Space

- **分类** Composition
- **常用别名** `["负空间", "留白", "空白空间", "negative space", "breathing room"]`
- **通俗说法** 在人物周围留出一大片视觉上较安静的区域，让距离和环境也能被感受到。
- **专业定义** 围绕或介于主要形体之间、在构图中承担关系与节奏的空间。可有纹理和色彩，其注意强度通常低于主要主体。
- **原理与条件** 以面积、方向、明暗和信息密度组织主体与周边关系。需结合视线方向、行动方向及交付画幅安排留白。
- **可见结果** 静帧可见人物偏置或较小、周围安静区域较大，形成期待、尺度或疏离等语境相关感受。
- **典型场景** 孤立人物、等待、给视线或行动预留方向、展示环境压力。
- **常见误解** 负空间可包含天空、墙面或低信息环境。其效果来自与主体的关系，保留叙事需要的环境线索仍很重要。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `观看目标`记录留白方向、面积与视觉中心，`机位`记录人物占比和观看关系。
- **迁移方法** 保留原场景结构，说明主体在画面哪一侧、空区位于何处。视频中空区被人物或事件填入的过程另写时间意图。

<a id="term-frame-within-frame"></a>
### 框中框 / Frame within a Frame

- **分类** Composition
- **常用别名** `["框中框", "内框构图", "门框构图", "frame within a frame", "internal framing"]`
- **通俗说法** 透过门、窗或其他边界看人物，让画面里再出现一层框。
- **专业定义** 利用场景中可见的边界、开口或形体组织出内部框架，引导注意并建立观察位置、空间层次或人物关系。
- **原理与条件** 内框与主体的距离、遮挡和明暗关系决定层次。边界可完整或局部出现，是否清晰按叙事需要确定。
- **可见结果** 静帧可见门窗等边界围绕主体，近处框架与远处行动建立嵌套空间。
- **典型场景** 透过门观察、人物被建筑约束、在多层空间中引导注意。
- **常见误解** 边界可以是不规则形体，内部框架也可偏置。画面装饰边框与场景内框需按用户语境区分。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`记录内框前后关系、遮挡与观看位置，`清晰关系`记录框架和主体可读性。
- **迁移方法** 优先使用当前场景已有门窗或形体，明确框架占比和主体位置。连续画面的进出框与遮挡揭示另写行动过程。

<a id="term-foreground-occlusion"></a>
### 前景遮挡 / Foreground Occlusion

- **分类** Composition
- **常用别名** `["前景遮挡", "前景遮幅", "遮挡构图", "foreground occlusion", "foreground masking"]`
- **通俗说法** 在眼前留一点门边、树叶或别人的肩膀，让人感觉隔着东西在看。
- **专业定义** 利用靠近观察位置的形体遮住部分画框或后方内容，以建立空间层次、视点身份、注意控制或信息保留。
- **原理与条件** 遮挡关系由机位、前景形体与主体位置决定。遮挡边界清晰程度取决于对焦与景深，运动中的揭示需实际位移或场景行动。
- **可见结果** 静帧中前景挡住部分环境或人物，形成距离、窥视或层次感。情绪含义依剧情与视点语境确定。
- **典型场景** 门后观察、越肩对话、树林中跟随、近景物件建立深度。
- **常见误解** 前景可清楚也可失焦。主体的重要表情和动作是否被挡住需要主动设计，遮挡占比与清晰度各自记录。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`记录遮挡形体、覆盖范围与主体关系，`清晰关系`记录前景和主体的清晰要求。
- **迁移方法** 使用场景已有前景或经授权的形体，明确遮挡哪一侧和哪些细节必须可见。连续变化沿用现有运动与连续性记录。

<a id="term-spatial-layers"></a>
### 空间分层 / Spatial Layers

- **分类** Composition
- **常用别名** `["空间分层", "前中后景", "纵深分层", "spatial layers", "depth staging", "foreground middleground background"]`
- **通俗说法** 让近处、中间和远处都有清楚的关系，画面看起来有纵深。
- **专业定义** 将人物、物件和环境按与观察位置的距离及遮挡关系组织成可读层次，可结合大小、透视、明暗和清晰度分配注意。
- **原理与条件** 机位和站位建立实际空间关系，重叠、相对尺度与透视提供深度线索。景深与光线可辅助层次，具体媒介沿用其空间表达方式。
- **可见结果** 静帧可辨认前中后景的尺度、遮挡和叙事联系。深焦可让多个层次同时可读，浅景深可把注意集中于其中一层。
- **典型场景** 多人物调度、人物与环境共存、通道或建筑纵深、建立行动因果。
- **常见误解** 分层可在各类视角中完成。较长焦距配合远机位仍可使用遮挡与明暗建立层次，清晰要求需按每个重要平面落实。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`记录距离、人物占比与前中后景关系，`清晰关系`记录关键平面，`观看目标`记录各层叙事任务。
- **迁移方法** 先列出每层必须存在的人物或环境线索，再选机位与清晰范围。视频中层次随行动变化时，沿用现有站位与 Shot Delta 管理。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["shot-revenant-camp", "shot-1917-basement"]` [营地场景卡](../cinema-shot-library.md#shot-revenant-camp)与[地下空间卡](../cinema-shot-library.md#shot-1917-basement)支持人物和纵深环境协同的方法，各卡未知实参继续保留。

<a id="term-rule-of-thirds"></a>
### 三分法构图 / Rule of Thirds

- **分类** Composition
- **常用别名** `["三分法", "三分构图", "九宫格构图", "rule of thirds", "thirds composition"]`
- **通俗说法** 把画面横竖各分成三份，让人物、眼睛或地平线靠近分界线。
- **专业定义** 以两条等距水平线与两条等距垂直线形成九宫格，将重要形体、视觉中心或分界安排在附近的构图启发法。
- **原理与条件** 通过位置和留白分配主体与环境的比重，需与视线、动作方向、亮度及最终画幅协调。位置允许按叙事灵活偏移。
- **可见结果** 静帧可见主体偏向约三分之一处，地平线或眼线与相应分界形成组织关系。
- **典型场景** 人物与环境平衡、对话留视线空间、风景中安排地平线。
- **常见误解** 该方法是一种构图选择，美感仍取决于具体关系。黄金分割有自己的比例，专业请求应保留用户采用的体系。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `观看目标`记录视觉中心、主体位置与留白，`机位`记录人物占比与地平线关系。
- **迁移方法** 用左侧或右侧三分线、上侧或下侧三分线说明重要位置，保留当前交付画幅。连续保持构图时另写跟随与调度要求。
