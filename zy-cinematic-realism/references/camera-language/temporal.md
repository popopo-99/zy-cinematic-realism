# 剪辑与时间镜头语法

从[摄影语言索引](../camera-language-dictionary.md)进入。这些概念依赖镜头与镜头、行动与时间的关系，沿用现有 Scene Master、Director 和连续性系统。静帧可承载单个状态，序列关系按用户请求记录。

<a id="term-insert-shot"></a>
### 插入镜头 / Insert Shot

- **分类** Editorial / Temporal Shot Grammar
- **常用别名** `["插入镜头", "细节插镜", "insert shot", "insert"]`
- **通俗说法** 在一段行动里插入手、信件或关键物件的细节，让观众注意到重要信息。
- **专业定义** 插入主行动覆盖中的细节镜头，以突出与该场景相关的物件、动作或信息。功能由前后镜头和叙事关系确定。
- **原理与条件** 通过画面尺度和剪辑位置集中注意，需保持物件状态、手部动作、方向和时间连续。与更广义的 Cutaway 按当前内容和功能区分。
- **可见结果** 单帧可直接呈现细节景别，作为“插入”的作用需前后镜头支持。序列可显示观众如何获得关键线索。
- **典型场景** 信件内容、手部动作、关键物件状态、行动中短暂可读的信息。
- **常见误解** 特写描述画面尺度，Insert 描述覆盖与剪辑功能。插入镜头可有多种焦距与机位，物件状态仍需继承当前场景。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `观看目标`记录细节的叙事任务，`机位`与`清晰关系`记录取景及焦点，`适用范围`记录所属镜头；前后关系沿用已有连续性记录。
- **迁移方法** 仅为当前情节中必要的物件制作细节图，继承道具、服装、手部动作与光源。用户需要序列时按已有镜头列表安排插入位置。

<a id="term-shot-reverse-shot"></a>
### 正反打 / Shot / Reverse Shot

- **分类** Editorial / Temporal Shot Grammar
- **常用别名** `["正反打", "反打", "对话反打", "shot reverse shot", "shot/reverse shot"]`
- **通俗说法** 先看说话的人，再转到另一边看回应的人，让两个人的关系接得上。
- **专业定义** 以相对或互补观看方向的镜头交替覆盖人物交流或空间关系，依靠视线、屏幕方向、景别和剪辑时机建立联系。
- **原理与条件** 需先确定人物站位、关系轴线、机位侧与视线目标。越肩和单人取景均可参与，角度与尺度可按叙事有意调整。
- **可见结果** 单帧可呈现一侧人物及其视线、肩部等线索，完整正反打关系需至少两个相关观看方向。
- **典型场景** 双人对话、对峙、观察与被观察、人物对物件或事件的反应。
- **常见误解** 正反打中的两个机位通常根据关系轴线安排，旋转180度的字面操作需具体核对。人物身份、服装与左右关系通过现有连续性记录继承。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `机位`记录观看侧、朝向、视线与人物占比，`适用范围`记录各镜头局部变化，轴线和镜头顺序沿用 Continuity。
- **迁移方法** 先保留同一场景和人物站位，再为每侧生成明确机位与取景。用户只要一张反打图时交付该侧画面，序列按已有连续性管理。

- **related_film_card_ids** `[]`

<a id="term-long-take"></a>
### 长镜头 / Long Take

- **分类** Editorial / Temporal Shot Grammar
- **常用别名** `["长镜头", "长时间镜头", "一镜到底", "long take", "oner", "single take"]`
- **通俗说法** 一段较长的行动持续在同一个观看过程中展开，让观众跟着事情发生。
- **专业定义** 相对影片节奏具有较长连续时长的镜头。拍摄层面的单次连续记录、成片中的表面连续段落和整部作品的一镜到底分别保留其证据范围。
- **原理与条件** 时间连续性依靠人物调度、机位、对焦、光线和声音等协同。隐蔽剪接可建立表面连续效果，真实拍摄连续性需制作资料确认。
- **可见结果** 连续画面可显示行动因果与观看位置的持续变化，也可在固定机位中展开。单张图只显示其中一个时刻，镜头时长需时间证据。
- **典型场景** 持续行动、群体调度、真实时间压力、让人物与空间关系逐步展开。
- **常见误解** 长焦描述镜头视角，Long Take 描述相对片中节奏的较长时长。Single Take 仅说明一次连续拍摄，也可以很短。“一镜到底”按用户语境确认是期望的连续外观、单段拍摄要求还是整片结构。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `观看目标`记录持续行动，`机位`与`清晰关系`记录过程依赖，`适用范围`记录段落时长，详细调度沿用现有 Director 与 Continuity。
- **迁移方法** 静帧选段落中叙事最明确的瞬间。连续请求保留行动因果、路径与焦点转换，生成模型能否维持所需时长和连续性另行核验。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["shot-revenant-camp", "film-1917"]` [营地场景卡](../cinema-shot-library.md#shot-revenant-camp)支持延长连续行动的方法，[《1917》影片卡](../cinema-shot-library.md#film-1917)提供持续移动摄影的制作语境；真实单次连续记录的范围需另有制作证据。

<a id="term-eyeline-match"></a>
### 视线匹配 / Eyeline Match

- **分类** Editorial / Temporal Shot Grammar
- **常用别名** `["视线匹配", "视线衔接", "eyeline match", "eyeline matching"]`
- **通俗说法** 先看见人物望向哪里，再接上他正在看的东西，方向和高度要让人相信。
- **专业定义** 通过人物视线与后续目标镜头的方向、角度及空间关系建立观看联系的剪辑组织，可与主观镜头和反应镜头组合。
- **原理与条件** 需明确观看者位置、视线目标、目标高度和机位关系。精确主观视点与叙事上可理解的视线连接按用户意图分别处理。
- **可见结果** 单帧可显示人物的视线方向，完整匹配需相关人物镜头与目标镜头。序列让观众将目标理解为人物所见。
- **典型场景** 人物发现线索、观察远处事件、双人交流、视线揭示空间信息。
- **常见误解** 向画面右侧看只给出部分线索，目标高度、距离和下一机位也会影响衔接。单帧的目光方向与完整剪辑关系分别核验。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `机位`记录人物朝向、视线、目标位置与观看高度，`适用范围`记录镜头关系，空间连接沿用 Continuity。
- **迁移方法** 保留当前人物与目标的三维位置，再确定各镜头方向。用户只要一张图时把视线目标和构图线索写清，序列用已有镜头列表连接。

<a id="term-180-degree-rule"></a>
### 180°轴线原则 / 180-degree Rule

- **分类** Editorial / Temporal Shot Grammar
- **常用别名** `["180度轴线原则", "180°原则", "轴线规则", "180-degree rule"]`
- **通俗说法** 两个人对话或有人沿一条方向行动时，先从同一侧拍，让左右和前进方向接得上。
- **专业定义** 以人物关系或行动方向建立轴线，连续覆盖通常把机位安排在轴线同一侧，以维持屏幕方向和空间可读性的剪辑原则。
- **原理与条件** 轴线来自当前人物位置、视线或运动方向，可随调度重建。跨越轴线时可用连续移动、轴上视点、重新建立的全景或其他明确空间线索交代变化。
- **可见结果** 相关镜头中人物左右关系、视线和行动方向可保持一致。单帧可记录轴线与机位侧，完整衔接须比较相邻镜头。
- **典型场景** 对话正反打、追逐方向、多人场面、需要清楚空间关系的连续镜头。
- **常见误解** Axis of Action 指人物关系或行动轴线，180°原则规定围绕该轴组织跨镜头机位的常用方法。用户只要求建立轴线时先记录空间关系。机头水平旋转180度与跨越关系轴线应按各自空间条件检查，越轴也可有明确创作意图。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `机位`记录观看侧、人物位置、朝向与运动方向，`适用范围`记录轴线所在段落，关系轴和跨镜头变化沿用 Continuity。
- **迁移方法** 先建立当前场景的人物位置和行动方向，再检查每个 Shot Delta 的机位侧。经授权的越轴写出空间重建方式，单帧只承载该时刻关系。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `[]`
