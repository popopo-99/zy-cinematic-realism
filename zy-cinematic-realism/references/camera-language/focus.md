# 清晰关系与成像行为

从[摄影语言索引](../camera-language-dictionary.md)进入。清晰分布、焦外形状、镜头内反射、滤镜散射与介质响应分别按其条件处理。器材卡提供候选依据，具体模型表现保留实际测试范围。

<a id="term-depth-of-field"></a>
### 景深 / Depth of Field

- **分类** Focus & Image Behavior
- **常用别名** `["景深", "清晰范围", "浅景深", "深景深", "深焦", "depth of field", "DOF", "deep focus", "shallow focus"]`
- **通俗说法** 画面从近到远，有多大一段距离看起来足够清楚。
- **专业定义** 在给定观看条件和可接受弥散标准下，对焦距离前后达到可接受清晰度的物方范围。浅景深范围较窄，深焦摄影追求多个重要纵深平面同时可读。
- **原理与条件** 光圈、焦距、对焦距离、有效成像区域及最终观看标准共同影响景深。背景虚化大小还取决于背景距离，极小光圈带来的衍射需同时考虑。
- **可见结果** 静帧可直接比较前、中、后景的清晰分布。深焦群戏让不同距离上的关键表情和动作同时可读，场景各处清晰度仍有实际边界。
- **典型场景** 浅景深突出眼神或物件，深景深交代环境或多个行动层次。
- **常见误解** 背景模糊程度还受背景位置影响，焦外形状另属 Bokeh。f 值保留几何光圈含义，T 值保留通光含义；两者的原始写法均应保留。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `清晰关系`记录光圈、对焦目标、必需清楚的平面与允许失焦区域，`镜头`与`机位`提供焦距和距离依赖。
- **迁移方法** 先指出必须看清的人脸、手或环境标志，再在 OPEN 站位、机位、光圈和对焦中求解。连续画面的清晰分布变化另外记录时间过程。
- **related_equipment_ids** `["lens-master-prime", "lens-laowa24-probe"]` [Master Prime](../equipment-library.md#lens-master-prime)与[Laowa Probe](../equipment-library.md#lens-laowa24-probe)提供不同摄影条件的候选，景深按具体任务落实。
- **related_film_card_ids** `["shot-barry-candle"]` [烛光赌局卡](../cinema-shot-library.md#shot-barry-candle)支持极浅景深与演员位置精确协调的场景方法，逐镜头参数保留未知项。

<a id="term-rack-focus"></a>
### 焦点转移 / Rack Focus

- **分类** Focus & Image Behavior
- **常用别名** `["焦点转移", "移焦", "拉焦", "rack focus", "focus pull", "pull focus"]`
- **通俗说法** 先看清前面的物件，再让后面的人变清楚。
- **专业定义** 在连续拍摄中改变对焦距离，将清晰重点从一个目标或平面转移到另一个。速度、时机和两端清晰范围按叙事要求确定。
- **原理与条件** 改变镜头对焦设定，使不同物距上的对象依次达到所需清晰度。目标距离、光圈、焦距、运动与镜头呼吸会影响结果。
- **可见结果** 时间序列中前后目标依次成为焦点，注意中心随清晰关系转移。单张图可显示其中一个状态，成对画面可显示起止差异。
- **典型场景** 从物件揭示人物、在双人关系间转移注意、让背景信息进入叙事。
- **常见误解** 浅景深描述当前清晰分布，Rack Focus 描述清晰重点在目标间的时间变化。拉焦、focus pull、pull focus 还可泛指调整焦点，例如持续跟随移动主体保持合焦；按用户是“换目标”还是“保持目标清楚”消歧。镜头呼吸的程度依实际器材与画面证据判断。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`、`video_instruction`
- **落入现有字段** `清晰关系`记录起止对焦目标、前后平面、清晰范围与转移时机，`适用范围`记录当前时刻或时间段。
- **迁移方法** 静帧明确选定当前焦点。连续指令写清先后目标、转移触发和时长，沿用当前 Scene Master 的人物与空间关系。

- **related_film_card_ids** `[]`

<a id="term-bokeh"></a>
### 焦外 / Bokeh

- **分类** Focus & Image Behavior
- **常用别名** `["焦外", "散景", "焦外成像", "bokeh", "out-of-focus rendering"]`
- **通俗说法** 已经虚掉的地方，看起来有多柔顺，亮点呈什么形状。
- **专业定义** 失焦区域的成像特征，包括模糊斑形状、边缘亮度、内部纹理、重叠方式和清晰到失焦的过渡。其品质判断具有场景和创作语境。
- **原理与条件** 镜头像差、光阑、光圈、画面位置、对焦距离、背景纹理与亮点共同作用。焦外亮斑依现有失焦光点形成。
- **可见结果** 静帧可见柔顺模糊、边缘明亮的圆环、椭圆或猫眼等形状，具体表现受位置与器材条件限制。
- **典型场景** 人像背景分离、夜景灯点、自然光斑、近摄背景处理。
- **常见误解** 景深决定可接受清晰范围，Bokeh 描述失焦部分的外观。圆形、椭圆等光点须有相应失焦高光条件，均匀墙面可呈平滑模糊。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `光学表现`记录焦外形状、过渡与作用范围，`清晰关系`记录对焦和失焦区域，`机位`记录主体背景距离。
- **迁移方法** 从当前背景的真实亮点和纹理出发，描述所需焦外形状与大小，保留人物结构与已锁定光源。随时间变化的焦外需另写对焦或光圈过程。
- **related_equipment_ids** `["lens-signature-prime", "lens-trioplan", "lens-atlas-orion"]` [Signature Prime](../equipment-library.md#lens-signature-prime)、[Trioplan](../equipment-library.md#lens-trioplan)与[Atlas Orion](../equipment-library.md#lens-atlas-orion)各有来源支持的候选外观，按条件取用。
- **related_film_card_ids** `["shot-batman-chase"]` [追车场景卡](../cinema-shot-library.md#shot-batman-chase)记录改装镜头的椭圆光阑及 Atlas Orion 等段落配置，各单镜头分配未知。

<a id="term-swirly-bokeh"></a>
### 旋焦 / Swirly Bokeh

- **分类** Focus & Image Behavior
- **常用别名** `["旋焦", "旋转散景", "旋转焦外", "swirly bokeh", "swirl bokeh"]`
- **通俗说法** 人物保持清楚，周围虚掉的树叶或亮点呈现绕着人物的环绕感。
- **专业定义** 外围失焦图样因镜头像差、离轴成像与渐晕等因素呈有方向的环绕趋势，具体形状和强度依镜头设计与使用条件变化。
- **原理与条件** 需有适当失焦背景、纹理或亮点，画幅与裁切、光圈、对焦距离、主体背景分离及主体画面位置均会影响表现。
- **可见结果** 静帧中主体附近保持所需清晰度，外围失焦叶片或高光呈环绕方向。实际强度随画面条件改变。
- **典型场景** 林间人像、具有密集细碎背景的近景、经授权的旧镜光学风格。
- **常见误解** 后期旋转模糊属于像素处理方法，镜头旋焦按失焦成像条件落实。相机环绕属于位置变化，人物和场景几何继续遵循各自结构。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `光学表现`记录强度与外围范围，`清晰关系`记录对焦目标和允许失焦区，`机位`记录主体背景距离，`镜头`保留指定型号。
- **迁移方法** 将目标写成中心主体清楚、外围失焦纹理环绕，协调现有背景与 OPEN 参数。静帧呈现光学外观，连续旋转运动须另有运动要求。
- **related_equipment_ids** `["lens-helios-44-2"]` [Helios 卡](../equipment-library.md#lens-helios-44-2)提供规格、候选条件和有限历史模型反馈，当前模型效果按实际结果核验。
- **related_film_card_ids** `[]`

<a id="term-lens-flare"></a>
### 镜头眩光 / Lens Flare

- **分类** Focus & Image Behavior
- **常用别名** `["镜头眩光", "耀斑", "鬼影", "lens flare", "flare", "veiling glare"]`
- **通俗说法** 强光进入镜头后，画面里可能多出光线、光斑，或局部像蒙上一层亮雾。
- **专业定义** 非成像光在镜头和相关光学系统中反射、散射，形成鬼影、光条或降低反差的幕状杂散光等表现。具体形态依设计与入射条件变化。
- **原理与条件** 强光在画内或画外以合适角度进入光学系统，镀膜、镜组、光阑、遮光和附件共同影响结果。水平光条需相关光学或滤镜条件。
- **可见结果** 静帧可见有来源方向的鬼影、光条、局部反差下降或遮蔽。变化过程需连续画面，真实镜头型号须资料支持。
- **典型场景** 逆光人物、夜间车灯、与光源方向共同承担叙事的画面。
- **常见误解** 焦外亮斑来自失焦高光，卤光是介质相关响应，扩散滤镜按散射特征处理。眩光形状还受光源角度与具体版本影响。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `光学表现`记录眩光形态、强度、范围与触发条件，`滤镜与介质`记录滤镜实现。光源沿用 Light / Value 的 Source Light Map。
- **迁移方法** 从现有强光方向安排受控效果，保留脸部与关键结构可读性。新增灯光按现有场景授权处理，时间变化另写光源或机位运动。
- **related_equipment_ids** `["lens-panavision-c", "lens-atlas-orion"]` [Panavision C](../equipment-library.md#lens-panavision-c)与[Atlas Orion](../equipment-library.md#lens-atlas-orion)提供厂家描述与必要条件，具体强度按型号和结果决定。
- **related_film_card_ids** `[]`

<a id="term-diffusion"></a>
### 扩散 / Diffusion

- **分类** Focus & Image Behavior
- **常用别名** `["扩散", "柔光滤镜", "黑柔", "diffusion", "diffusion filter", "optical diffusion"]`
- **通俗说法** 让亮光边缘柔一点、细部锐利感缓一点，同时保留需要看清的脸和物件。
- **专业定义** 本条以成像端光学扩散为主，借助滤镜等散射部分光线，改变高光扩散、局部反差和细节表现。灯光端扩散另按照明设计解释。
- **原理与条件** 滤镜类型和强度、光源亮度及尺寸、焦距、光圈与景别共同影响结果。数字柔化按后期实现单独记录。
- **可见结果** 静帧中强光周围柔和溢出，局部反差与细部锐利感可能降低。面部保留程度需根据目标明确，动态变化依光源和运动过程描述。
- **典型场景** 柔顺人物质感、减轻过强数字锐利感、让现有灯光柔和扩散。
- **常见误解** “柔光”也可能指大面积柔和照明，先按语境消歧。天气雾在场景空间中散射光，卤光按介质记录，各自影响范围需明确。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `滤镜与介质`记录类型、档位与实现，`光学表现`记录高光扩散范围；表面细节沿用 Surface / Rendering。
- **迁移方法** 保留用户指定滤镜档位，补齐需要柔化的区域和必须清楚的眼睛、轮廓与材料。照明仍由当前光源方案管理。
- **related_equipment_ids** `["filter-black-pro-mist"]` [Black Pro-Mist](../equipment-library.md#filter-black-pro-mist)提供厂家资料，档位与实际画面效果按当前任务落实。
- **related_film_card_ids** `[]`

<a id="term-halation"></a>
### 卤光 / Halation

- **分类** Focus & Image Behavior
- **常用别名** `["卤光", "胶片卤光", "高光红晕", "halation", "film halation"]`
- **通俗说法** 很亮的灯或高反差边缘周围，出现一圈贴着亮边的柔和光晕。
- **专业定义** 胶片成像中，光穿过感光层后在支持层或背面反射、散射并再次曝光感光层，可能在强亮边缘产生扩散光晕。防卤光结构与片种影响其程度和颜色。
- **原理与条件** 需要足够强的局部高光与暗亮交界，具体介质、曝光及后续流程共同决定外观。数字模拟按后期成像选择记录。
- **可见结果** 静帧中强亮边缘邻近区域形成局部光晕，某些介质可呈红色或偏暖色。连续变化随高光移动与曝光变化，须另有时间描述。
- **典型场景** 夜景灯源、暗背景强高光、经用户选择的胶片或胶片模拟外观。
- **常见误解** 红色卤光的具体色相需要片种或创作依据。镜头鬼影、滤镜扩散和空气雾各自按对应原理处理，电影实拍介质须制作记录支持。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `滤镜与介质`记录片种或后期模拟，`光学表现`交叉引用局部作用范围；高光与最终表面表现沿用 Surface / Rendering。
- **迁移方法** 沿场景现有强高光边缘指定局部强度与颜色，保留人物与暗部细节。引用静态负片外观时保留其用途与证据范围。
- **related_equipment_ids** `["media-cinestill-800t"]` [CineStill 800T](../equipment-library.md#media-cinestill-800t)的静态摄影厂家资料支持暗背景强高光红色卤光，电影制作使用记录留待核验。
