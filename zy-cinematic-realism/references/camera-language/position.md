# 机位位置与朝向

按[词典索引](../camera-language-dictionary.md)读取所需条目。机位高度、朝向、距离和观看侧分别记录，情绪含义由场景共同决定。静帧可观察构图关系，画面所暗示的真实拍摄位置、角色主观归属或运动过程须保留推断边界。

<a id="term-low-angle"></a>
### 仰拍 / Low Angle

- **分类** Camera Position & Orientation
- **常用别名** `["仰视", "低角度仰拍", "Low-angle Shot"]`
- **通俗说法** 从下方向上看人物或建筑。
- **专业定义** 摄影机朝向向上，与主体形成仰视关系。摄影机高度、主体高度和俯仰角分别记录，低高度机位可有多种朝向。
- **原理与条件** 主体相对高度、机位距离、仰角和视角共同决定形状与占比。近距离时近侧部位可能更突出，建筑竖线会呈相应汇聚关系。
- **可见结果** 静帧显示主体向上延伸、天空或天花进入构图。连续向上转动属于机头俯仰运动，须另外提供过程与时间。
- **典型场景** 强调人物的体量、儿童视点、建筑高度、受压迫者向上观察的视点。
- **常见误解** 低机位确定高度，仰拍还需向上的朝向。威严、脆弱或荒诞等含义取决于动作、表情与场景，焦距与距离也会影响比例。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的高度、距离与俯仰、`观看目标`的情绪作用、`镜头`的视角。
- **迁移方法** 将“贴地看他”解析为低高度，再根据人物位置确定向上朝向和占比。保留现有场景，通过构图与动作落实所需力量感。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["shot-favourite-room"]` [宫廷场景卡](../cinema-shot-library.md#shot-favourite-room)支持高低机位的方法描述，各单镜头实际高度与仰角未知。

<a id="term-high-angle"></a>
### 俯拍 / High Angle

- **分类** Camera Position & Orientation
- **常用别名** `["俯视", "高角度俯拍", "High-angle Shot"]`
- **通俗说法** 从上方向下看人物，能多看到脚下和周围的关系。
- **专业定义** 摄影机朝向向下，与主体形成俯视关系。摄影机高度与向下俯角需分别确定，具体角度可以从轻俯到接近顶视。
- **原理与条件** 高度、俯角、距离和视角共同影响头身比例、地面占比和遮挡关系，高处水平观看仍需按其实际朝向描述。
- **可见结果** 静帧可显示更多地面、头顶或人物在空间中的位置。由平视转成俯视的运动需连续画面才能确认。
- **典型场景** 展示人物受环境包围、桌面行动、队形站位、观察低处人物或地形。
- **常见误解** 俯拍的情绪可能是脆弱、冷静观察或空间说明，需依剧情判断。顶视有更明确的近乎垂直朝向，俯拍范围更广。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的高度、距离与俯角、`观看目标`的空间关系、`清晰关系`的地面与人物范围。
- **迁移方法** 先确定需要看到的地面关系和人物大小，再安排俯角与高度，视频中需要的朝向变化另记起止状态。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `["shot-favourite-room"]` [宫廷场景卡](../cinema-shot-library.md#shot-favourite-room)提供高低机位组织空间的方法，单镜头具体朝向未知。

<a id="term-eye-level"></a>
### 平视 / Eye Level

- **分类** Camera Position & Orientation
- **常用别名** `["眼平机位", "Eye-level Shot", "视线高度"]`
- **通俗说法** 像站在人物对面，以差不多的眼睛高度看他。
- **专业定义** 摄影机大致处于所关注主体的眼睛高度，以接近水平的观看关系取景。主体的身高、坐姿与所采用的观察者视点共同确定基准。
- **原理与条件** 高度、朝向和距离分别安排，水平视轴与主体眼睛高度可以同时成立，也可能因构图需要存在小幅俯仰。
- **可见结果** 静帧呈现接近日常面对面交流的观看关系，明显的仰俯强调较少。单帧只能支持视觉判断，精确机位高度需要拍摄资料。
- **典型场景** 平等交谈、自然人像、观察性场面、需要克制观看立场的画面。
- **常见误解** 平视可采用多种距离和焦距，亲近感还受镜头距离与表演影响。角色坐下后，眼平基准随该主体重新确定。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的高度与朝向、`镜头`的视角、`观看目标`的观看关系。
- **迁移方法** 指明相对于哪位人物及其姿态的眼高，再确定景别与距离。静帧保留当前观看状态，视频中的高度调整单独说明。

- **related_film_card_ids** `[]`

<a id="term-overhead"></a>
### 顶视 / Overhead

- **分类** Camera Position & Orientation
- **常用别名** `["正顶拍", "Top Shot", "Top-down Shot", "Bird's-eye View"]`
- **通俗说法** 从正上方往下看，人物和物件像铺在同一张地图里。
- **专业定义** 摄影机位于主体上方，视轴接近垂直向下的观看关系。Bird's-eye View 在口语中也可指较宽泛的高处俯视，执行时需明确是否正顶视。
- **原理与条件** 向下朝向、拍摄高度和所需视场共同控制形状、遮挡及图案关系。高处斜俯视与垂直顶视需要分别确定角度。
- **可见结果** 静帧突出平面布局、人物队形与桌面几何，脸部可能因姿态而难以看清。升至顶视或下降过程需要连续证据。
- **典型场景** 餐桌、工作台、楼梯、队形、地面线索、以图案组织行动的场面。
- **常见误解** 顶视由朝向与位置定义，实现方式可以多样。航拍设备、吊臂或具体高度须按需求与证据决定。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的高度、朝向与主体占比、`清晰关系`的平面范围、`观看目标`的布局信息。
- **迁移方法** 明确镜头垂直向下、需要完整入画的地面范围及人物动作，再选择视角和高度。角色身份与道具沿用当前场景。

- **related_film_card_ids** `[]`

<a id="term-dutch-angle"></a>
### 荷兰角 / Dutch Angle

- **分类** Camera Position & Orientation
- **常用别名** `["倾斜构图", "Dutch Tilt", "Canted Angle", "斜角镜头"]`
- **通俗说法** 整个画面的地平线斜着，让观看有点失衡。
- **专业定义** 摄影机绕观看轴形成一定滚转角，使画面中的水平或竖直参考线相对画框倾斜的静态朝向。角度可固定，也可作为滚转运动中的一个状态。
- **原理与条件** 需要可识别的建筑、地面或其他方向参照，倾角、主体姿态和画幅共同影响失衡程度。
- **可见结果** 静帧可直接观察倾斜的参考线和画框关系。连续改变倾角属于 Roll，单帧无法证明曾发生滚转。
- **典型场景** 眩晕、心理失衡、紧张动作、经授权的形式化构图。
- **常见误解** 荷兰角表达静态倾斜，机头向上或向下俯仰涉及另一旋转轴。角色或地形本来倾斜时，还需结合其他参照判断。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的滚转角与构图、`观看目标`的失衡程度，并保护原有人物占比和场景关系。
- **迁移方法** 指明地平线倾斜方向与大致程度，保留主体姿态和几何结构。若用户要求持续旋转，再单独记录时间与起止角度。

- **related_film_card_ids** `[]`

<a id="term-over-the-shoulder"></a>
### 越肩 / Over-the-shoulder

- **分类** Camera Position & Orientation
- **常用别名** `["过肩镜头", "OTS", "Over Shoulder", "越肩镜头"]`
- **通俗说法** 近处留一点这个人的肩膀，从他身旁看向另一个人。
- **专业定义** 摄影机位于前景人物肩后或肩侧，以部分肩头、后脑等作为近景参照，观看对面人物或目标的取景关系。可结合不同景别与机位高度。
- **原理与条件** 前景人物位置、摄影机观看侧、对方视线及遮挡范围共同决定关系，景深和焦点需根据当前注意中心安排。
- **可见结果** 静帧可见近侧肩头与远侧对象的关系，前景可清晰或失焦。正反打及视线连续性需要结合相邻画面，单帧不证明剪辑成立。
- **典型场景** 双人对话、审讯、人物看向物件、用近景身体建立关系与距离。
- **常见误解** 越肩可采用中景或特写，焦距另定。前景人物占比与颜色应继承场景，越肩视点的角色归属和 POV 需按叙事语境区分。
- **呈现方式** `directly_visible_in_still`
- **落入现有字段** `机位`的观看侧、距离与人物占比、`清晰关系`的前景肩头和远侧目标，并协调 Camera / Viewpoint 的遮挡。
- **迁移方法** 明确越过谁的哪侧肩膀、看向谁、肩头占画面多少，再安排远侧人物的视线和对焦。系列反打沿用连续性系统的轴线与站位。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `[]`

<a id="term-pov"></a>
### 主观视点 / POV

- **分类** Camera Position & Orientation
- **常用别名** `["主观镜头", "Point of View", "第一人称视点", "POV Shot"]`
- **通俗说法** 让观众像借着这个人的眼睛，看他正在看的东西。
- **专业定义** 将摄影机视点与特定角色的视觉位置、方向或主观感受关联的叙事观看方式。严格视觉位置与更宽泛的主观感受需按任务区分，归属通常由上下文建立。
- **原理与条件** 角色视线、眼高、朝向和所见对象需相容，手臂或遮挡可提供线索。角色看向某物的前后镜头能加强归属证据。
- **可见结果** 静帧可暗示第一人称空间关系，单帧通常无法独立证明视点属于哪位角色。主客观切换和视线匹配需要序列，视频动作再记录时间。
- **典型场景** 角色发现线索、行进中的体验、受限视野、互动叙事中的第一人称观看。
- **常见误解** 近距离广角可以增强参与感，角色主观归属仍需叙事依据。手持、头部晃动与游戏界面属于可选表现，按授权加入。
- **呈现方式** `inferred_or_suggested_in_still`、`requires_temporal_sequence`
- **落入现有字段** `观看目标`的视点归属、`机位`的眼高与方向、`清晰关系`的所见目标，并继承场景人物位置。
- **迁移方法** 先确定是谁在看、从哪里看以及看见什么，再将眼高、遮挡和空间关系写进当前画面。静帧交付明确为该角色视点下的一个时刻。
- **related_equipment_ids** `[]`
- **related_film_card_ids** `[]`
