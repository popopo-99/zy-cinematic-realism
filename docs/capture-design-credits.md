# 摄影设定功能的贡献与来源

本文记录造梦师 v2.7.0 摄影设定的来源、贡献与实施范围。

## 致谢 Jury

感谢 Jury 对造梦师摄影能力的探索、资料整理与实践反馈。摄影设定功能的重要启发来自 Jury 提供的 Skill 迭代方案、双入口使用手册、Jury JSON Brief，以及器材视觉签名参考材料。

本次参考的材料包括 Jury 于 2026-10-16 提供的迭代资料、《造梦师_双入口版使用手册_v2.5.3.md》、《Jury_JSON_Brief.md》与《器材视觉签名参考包_清单重建版_v1.2.md》。这些材料帮助明确了器材选择、成像条件与提示词表达之间需要建立的联系。

| Jury 的贡献方向 | 这次升级吸收的内容 | 正式版中的落点 |
| --- | --- | --- |
| 器材视觉签名 | 将器材名称与能看见的光学、色彩、景深或表面表现联系起来，并关注效果条件 | 按需查询的器材卡，以及“设备信息加可见结果”的提示词表达 |
| 成像规划 | 根据新需求或实际参考整理机身、镜头、光学、光色和介质选择 | 写入同一 Scene Master 的摄影设定，并与光源、材料字段协同 |
| 结构化摄影字段 | 将机身、镜头、焦距、清晰关系、颗粒和高光等决策明确记录 | 内部摄影记录与按需 JSON 导出 |
| 资料与推断的区分 | 区分实际视觉依据、器材资料、重现建议与生成反馈 | 器材与电影卡的来源范围、状态标记和可迁移说明 |
| 迭代反馈 | 注意相同词句在不同画幅、模型和场景中的表现差异 | 保留具体使用条件和来源，使用反馈按其实际条件记录 |

这些贡献在[摄影设计参考](../zy-cinematic-realism/references/capture-design.md)中有直接致谢。器材和电影条目保留各自可核查的资料链接。

## 原有造梦师系统

造梦师由 ZY / popopo-99 创建并维护。v2.7.0 以官方 v2.6 代码与文档为基线，原有的 Scene Master、Creative Grammar、模型编译与结果修复链路为摄影设定提供统一的场景基础。

原有系统已经包含剧本到画面、导演四轴、解梦与参考职责、媒介识别、连续性、视觉资产包、项目交接和多模型适配等能力。摄影设定接入这些能力，使观看位置、器材选择与成像表现能够跟随同一场景共同修改。[项目仓库](https://github.com/popopo-99/zy-cinematic-realism)

## v2.7.0 的实施内容

本次实施围绕用户提出的两类表达深度展开。日常语言从观看感受进入，专业语言从器材与参数进入，两者汇入同一个摄影记录。

- 将摄影设定纳入 Scene Master 的 `Camera / Viewpoint`，协调现有光源、表面与交付字段。
- 默认自动补齐开放选择，并交付普通文本提示词。
- 通过可见目标进行口语引导，按需要呈现专业深度。
- 建立可按需查询的器材与电影摄影卡，记录事实支持范围。
- 记录用户锁定、系统开放项、来源及项目或镜头范围，处理参数依赖和累计修改。
- 按请求导出结构化数据，并沿用用户提供的字段结构。
- 将摄影选择接入导演方法、解梦、连续镜头、参考资产、项目交接与跨模型编译。
- 新增 Seedream 5.5 独立适配，保留明确指定 Seedream 5.0 Pro 的使用路径。

摄影设定、器材库、电影库、适配器和用户指南是本次整理实施的内容。Jury 的贡献在上述思路与具体材料中记录，原有造梦师的系统归属继续按项目署名标明。

本次交付的使用示例用于说明请求方式。生成能力、模型表现与改进幅度需要依据对应的实际结果和条件描述。

## 厂家资料、制作资料与电影证据

器材和电影资料服务于选型与创作。引用时保留原来源、核实日期以及被支持的具体结论，按照材料的覆盖范围表达。

| 来源 | 适合支持的结论 | 使用时保留的范围 |
| --- | --- | --- |
| 厂家产品页和技术资料 | 型号、规格、设计说明与厂家描述的效果条件 | 对应产品、版本及原文说明范围 |
| 摄影师、主创或制作访谈 | 选择器材或拍摄方法的理由、采访中明确谈及的段落 | 受访者、作品、段落与原始上下文 |
| ShotOnWhat 等影片器材记录 | 影片制作中记录的机身、镜头、胶片等配置 | 影片级或条目明确说明的范围 |
| 实际剧照、参考图或片段 | 可直接观察到的构图、光线、人物关系、材料与清晰层次 | 实际查看的图像或时间范围 |
| 当前场景的重现建议 | 将某种观看方式落实为可执行的机位与成像设计 | 建议所依据的目标、条件与尚开放的参数 |
| 用户生成反馈 | 某次提示词在相应模型、画幅、输入和使用条件下的结果 | 已提供的原始词句、输入、版本与实际反馈 |

整片器材资料与单镜头摄影证据分别保存。精确到某个镜头的型号、焦距或光圈，需要与该镜头对应的来源。仅从成图观察时，可以描述可见特征与合理候选，判断依据按实际可见内容记录。

厂家效果说明和用户生成反馈也各有适用条件。来源中的营销描述按厂家表述引用，生成表现按实际使用结果记录。具体模型版本、提示词或画幅变化后的结论，需要对应条件下的依据。

## 来源如何继续维护

器材与电影卡在相关条目旁保留来源链接、核实日期和支持范围。新资料补充时，更新受影响的结论。遇到资料冲突时保留冲突内容与来源上下文，尚未覆盖的参数保持待确认状态。

用户反馈可补充原提示词、模型版本、画幅、参考输入和结果说明，便于后续理解适用条件。经改写的表达使用其自身记录，来源事实与重现选择分别维护。

新增或修订资料时优先维护对应的器材卡、电影卡或模型适配器，再同步影响到入口和用户指南。普通生成提示词主要携带画面要求，完整资料依据按查询和说明任务提供。
