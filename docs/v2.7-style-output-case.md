# 同一画风，两种输出 · 天文台A/B实际案例

本案例在 v2.7 摄影设定预览期间完成。用户提供两张 Lovart / Seedream 5.5 实际回图，每组 1 张。本页公开两份原始提示词及对应的观察记录。

## 共用的创作意图

以此前案例A作为Style Reference，继承三渲二动画的造型概括、分组明暗、材质简化、局部手绘纹理和低饱和冷暖关系。新内容为白发男性在古老木质观测台内调校黄铜星盘，背景包含大型望远镜、木梁和侧窗天空。

两组准备时共用Scene Master、Active Core Rules、参考职责、21:9画幅和Seedream 5.5目标。普通文本完整表达场景与颜色职责，B组使用同一意图并附15个近似HEX设计色值。两组均按用户说明使用原案例A作画风参考。

## 两张回图的观察记录

两张均建立了白发新人物、黄铜器械和观测台环境，未见明显源胸甲、废墟或塔楼内容泄漏。A的盘面接近竖直，色面与细节相对克制。B的盘面明显倾斜，桌面还出现了原提示词未指定的书本和散放圆盘，镜头视点与背景布局也有变化。其物件细节更多，同时存在对共用设定的执行偏差。

本例尚未建立JSON + HEX的质量优势。系列画风应看造型、明暗、边缘、材质与颜色职责的延续，同时记录场景遵循度，精致程度单独评价。

## HEX在这里承担什么职责

B组前14色沿用此前参考案例提供的设计色值，第15色为白发和袖口补充。灰绿用于长袍，冷青灰用于天空与环境，暖米桃用于肤色，浅金米用于黄铜，暖褐用于木结构，浅灰白用于白发和布袖口。具体数值和职责保存在B组Color Palette与hex_values中。

这些颜色属于近似设计锚点，未经精确像素采样。受光与阴影仍会改变同一材质的可见颜色，HEX字段在当前入口中的实际执行程度需结合回图判断。

## 已知条件与证据范围

- A/B身份按用户整理包固定，图片与提示词均按原始字节归档。两份提示词与此前冻结准备包一致，两张图均为2048×878，接近21:9。
- 平台和模型由用户报告为Lovart / Seedream 5.5。实际任务日志、种子、参考强度、自动改写及模型精确构建版本记录未齐。
- 每组仅1张，且B同时改变结构化格式与HEX明确值，无法分离其各自贡献。生成随机性和平台处理也可能影响差异。
- 当前结果支持两种交付的单次实际展示，长期系列稳定性及精确器材或生产工艺复现尚待对应证据。
