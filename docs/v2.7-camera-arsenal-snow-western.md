# 造梦师 v2.7.0 摄影武器库｜一句话设计雪地西部片

**真实文本调用案例 · 记录于摄影设定预览期间**

想让雪原看起来广阔，就让人物在画面里小一些，给雪地和远山留出空间。用低角度侧光照出雪脊的明暗，地形的起伏就更容易看出来。你可以先说想看到什么，再让造梦师解释器材和拍法。

## 1. 口语需求

调用的 Skill 为 `$zy-cinematic-realism-capture-preview`（摄影设定预览版）。

用户的摄影需求原句如下。

```text
我想在雪地里拍一张具有史诗感的西部电影画面，帮我选择合适的摄影机和镜头，并解释为什么。
```

## 2. 器材检索

这次调用查阅了器材库、摄影设定和摄影语言索引，并打开了 ARRI Rental 的两份官方资料。Skill 最终推荐 **ARRI ALEXA 65 + ARRI Rental Prime 65 50mm 球面定焦镜头**。这套组合的取景比较开阔，画面可以同时容纳人物、雪原和远山。人物在画面里占多大，还要结合摄影机离人物多远来决定。

## 3. 摄影方案

以下参数是本次创作建议。实际拍摄时可按现场距离、光线和构图微调。

| 选择 | 怎么拍 | 画面上看什么 |
| --- | --- | --- |
| 人物和雪原的尺度 | 摄影机离人物约 15–20 米，机位略低，镜头基本水平。站立人物约占成片高度的五分之一到四分之一。 | 一眼能找见人物，也能看见大片雪地怎样围绕着人展开。 |
| 人物与地形的清晰范围 | 对焦人物，从 T5.6–T8 起步，再检查远处地形是否足够清楚。 | 人物仍是视觉中心，雪原和山体也有足够可读的形状。 |
| 光线和曝光 | 优先选低角度侧光，按雪面保留纹理控制曝光。 | 雪脊有亮面和阴影，开阔的白色区域仍能看出起伏。 |
| 宽银幕构图 | 以 Open Gate 记录，成片裁成 2.39:1。 | 用横向空间安排人物、雪原和远山。2.39:1 是本案的交付画幅。 |

我会选 **ARRI ALEXA 65 + ARRI Rental Prime 65 50mm 球面定焦镜头**，用 **2.39:1 宽银幕构图**。这套选择适合“人物置身辽阔雪原，荒野具有压迫感”的西部片画面。

**摄影机选 ALEXA 65：让环境细节经得起观看。**  
它采用 65mm 格式传感器，原生记录约 6.5K，适合保留雪面起伏、远处山体和人物衣物的细节。官方标称超过 14 档动态范围，也为明亮积雪与深色衣物同时保留层次提供余地；拍摄时仍需控制曝光，保护大面积雪面的纹理。[原厂资料](https://www.arrirental.com/en/cameras/digital-65-mm-cameras/alexa-65)

**镜头选 Prime 65 50mm：兼顾开阔环境与人物分量。**  
这个系列是覆盖 ALEXA 65 完整成像区域的配套镜头。50mm 在这块大画幅上的水平视角，约相当于全画幅相机的 **33mm**，已经相当开阔。我会用它同时容纳人物和大片地形，并通过拍摄距离控制人物比例。原厂对该系列清晰、反差鲜明的描述，也符合我希望保留雪脊和粗厚衣料质感的方向。[镜头资料](https://www.arrirental.com/en/lenses/65-mm-lenses)

我会这样落实这套配置：

- **机位与尺度：** 距人物约 15–20 米，机位略低、基本水平，让站立人物高度约占画面的五分之一到四分之一，留出大片雪原。
- **景深：** 从 **T5.6–T8** 起步，对焦人物，再检查远处地形是否足够清楚，让环境参与叙事。
- **光线：** 优先选择低角度侧光，用雪脊的明暗变化显出地形；曝光以保留大面积雪面纹理为准。
- **宽银幕：** Open Gate 拍摄后裁成 2.39:1，用横向空间组织人物与荒野的关系。

这张画面的史诗感，主要来自**人物与荒野的尺度差、清楚的空间层次，以及有方向的光线**；器材负责把这些关系完整地记录下来。
