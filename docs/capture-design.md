# 造梦师 v2.7.0 摄影设定使用指南

本指南对应造梦师 v2.7.0。安装完整 Skill 后，用 `$zy-cinematic-realism` 调用。[安装与升级指南](getting-started.md)

## 本次升级要解决什么

当你说“像站在人物身边”“背景别太虚”“换成某个镜头的感觉”，造梦师会把这些要求落实到观看位置、构图、景深、焦点与成像表现。你也可以直接指定摄影机、镜头、焦段、光圈、滤镜和成像介质，再让它完成其余选择。

这次升级把摄影设定接入现有创作链路。

```text
用户的故事、场景或参考
        ↓
当前场景记录 Scene Master
  ├─ 人物、动作、环境与空间
  ├─ 摄影设定与观看位置
  ├─ 光源、色彩与材料表现
  └─ 画幅、参考职责与限制
        ↓
按所选模型生成提示词
        ↓
根据实际结果与反馈继续修改
```

摄影设定和人物、动作、光源共用一份当前场景记录。后续改景深、换焦段或切换模型时，可以接着已有选择完成工作。

主要新增内容包括口语化摄影引导、专业器材武器库、带来源的电影摄影参考、参数联动、摄影选择的继承与修改，以及 Seedream 5.5 的独立适配。普通文本是默认的提示词交付形式。

## 一个入口，两种表达深度

继续使用 `$zy-cinematic-realism`，也可以直接说“用造梦师”。你提供日常语言时，它用观看效果和你沟通。你提供专业参数时，它保留这些参数并继续设计。

| 你怎么说 | 造梦师如何处理 |
| --- | --- |
| “树林里一个人，像我就在他旁边看着他” | 确定人与摄影机的距离、人物占比和空间亲近感，再补齐必要参数 |
| “别把后面的店铺虚掉” | 将店铺设为必须可读的背景信息，联动景深、对焦与站位 |
| “用 Sony α7 IV 和 Helios 44-2，f/2” | 保留设备与光圈，在剩余的机位、构图和距离中完成方案 |
| “给我讲讲 35mm 和 85mm 怎么选” | 结合你当前要拍的人物和环境，解释两种方案需要的观看距离与画面差异 |
| “我想看看有哪些经典镜头可以用” | 查询相关器材或电影卡，提供少量有区别的方向供你选择 |
| “器材你选，直接出词” | 补齐开放选择，直接交付提示词 |

系统根据这次请求需要的深度回答。你可以随时从口语描述切换到专业参数，也可以要求把专业解释讲得更直白。

### 引导会问什么

你已经说明画面要求时，造梦师直接完成合理的空白。你需要帮助选择时，它优先讨论一项真正能看出差异的目标，例如更贴近人物、更能看清环境，或让眼神成为注意中心。

只有一个真实冲突或不可替代的缺失输入会挡住结果时，才需要进一步确认。例如你同时锁定极浅景深、前后相距很远的两个人，以及两张脸都必须同样清楚，造梦师需要确认可调整的条件。

你说“你决定”“直接给提示词”后，未指定的摄影项由造梦师完成。想看选型过程时，可以主动要求“先给我摄影方案并解释原因”。

## 口语怎样变成摄影设定

| 口语要求 | 画面中实际需要解决的事 |
| --- | --- |
| “像站在他旁边” | 近距离观看、人物与环境的比例、面部距离和空间邻近关系 |
| “离他远一点，像远远看到他” | 观看距离、人物占画面大小、前后景尺度与遮挡 |
| “背景还能看清” | 哪些环境线索必须可读、人物与背景距离、景深和焦点 |
| “只突出他的眼神” | 眼睛清晰度、人物景别、背景干扰和明暗主次 |
| “人物后面的山看起来近一点” | 机位距离、人物占比、远景尺度和相应焦段 |
| “背景绕着人物轻轻转” | 中心清晰、外围失焦纹理的形态、镜头特征与背景条件 |
| “有老电影的味道” | 所需年代、色彩、反差、颗粒、高光或介质表现 |

同一句口语可能有不同的实现方式。造梦师根据当前空间、人物动作、已有光源和你锁定的条件完成选择。需要解释时，会说明这次具体采用了什么方式。

## 专业用户如何使用武器库

武器库在你要浏览、查型号、比较方案、研究电影摄影或实现特殊效果时按需调用。普通场景也可以完全交给造梦师设计。

### 器材卡

器材卡帮助你把型号与画面表现联系起来。浏览时重点看以下信息。

- 型号或系列，以及画幅、焦距等适用信息。
- 画面中可见的特征，例如背景形态、边缘表现或高光响应。
- 效果成立需要的距离、光圈、背景和光源条件。
- 适合当前任务的可复制表达。
- 来源及其支持的事实范围。

例如你要树林旋焦，可以按“外围失焦纹理轻微环绕，中心眼睛清楚”查找候选方案。你要双人室内戏，可以按观看距离、人物站位和两张脸的清晰要求比较方案。

型号查询、候选推荐、选型应用可以分别提出。你只问器材资料时，造梦师交付相应资料。你接着说“就用这个，帮我写提示词”时，它把选定信息写入当前场景。

完整条目见[器材武器库](../zy-cinematic-realism/references/equipment-library.md)。

### 电影摄影卡

电影卡围绕作品与拍摄方法组织资料，帮助你查找导演、摄影师、影片、相关设备与可迁移的摄影做法。看一张电影卡时，需要留意资料具体谈的是整部影片、某个段落，还是一个有明确证据的镜头。

| 资料类型 | 可以支持的使用方式 |
| --- | --- |
| 影片器材记录 | 确认影片制作中使用过的摄影机、镜头或胶片等配置 |
| 摄影师或主创访谈 | 理解选型、机位、照明或某段落的设计依据 |
| 实际剧照或片段 | 分析能够看到的构图、人物关系、光线与焦点 |
| 针对当前场景的重现方案 | 提出适合你的人物、空间与目标模型的摄影选择 |

具体镜头的精确焦距、光圈或滤镜需要相应证据。资料尚未覆盖的参数，造梦师会按当前任务提出可审阅的选择。用户需要的作品背景、人物关系和摄影效果分别进入对应的场景设定。

完整条目见[电影摄影参考库](../zy-cinematic-realism/references/cinema-shot-library.md)。

## 参数如何联动

### 机位、焦段与画幅

观看距离会改变人物与环境的透视关系。焦距在同一有效画幅上改变取景范围。因此，你提出“换长焦但人物还是一样大”时，造梦师会一起考虑摄影机距离与背景尺度。

实际焦距、等效视角和交付画幅分别记录。例如 58mm 是镜头实际焦距，16:9 是成图比例。等效视角需要有效画幅和裁切依据。缺少这些信息时，可以保留实际焦距，并直接说明你希望的构图和观看关系。

### 光圈、对焦与清晰范围

景深需要结合光圈、焦距、距离与人物前后位置。造梦师先确定哪些东西必须清楚，再选择能够支持它们的设置。你锁定大光圈时，可以在允许的站位、机位和对焦范围内继续设计。

专业参数保留原有写法，包括摄影镜头的 f 值和电影镜头的 T 值。你也可以只指定“眼睛和手里的信都要清楚”，让造梦师完成成像方案。

### 光学效果、滤镜与介质

旋焦、镜头眩光、滤镜扩散、胶片卤光和雾气散射有各自的条件。选择其中一项时，会保留它的作用区域、强度与场景依据。

例如旋焦需要合适的背景纹理和距离分离。镜头眩光需要对应的强光方向。雾气取决于天气与空间设定。造梦师依据已经允许的场景条件设计效果，明确需要新增环境或光源时再与当前要求协调。

机身、镜头、胶片、滤镜与色彩处理分别描述。你可以要求数字拍摄基础、柔和色彩、轻微扩散和清晰眼睛，并让它们形成相容的方案。

## 哪些选择会被保留

你明确指定或具体采纳的设备、参数、机位和效果按相应范围记为用户锁定。例如“就用 58mm”会锁定该字段。仅说“这张图不错”时，按你实际认可的外观范围记录，内部未展示参数继续保持原状态。来源、锁定与接受状态分别保存。授权参考在你指定的职责和迁移范围内参与摄影设计。

| 你提出的范围 | 适用方式 |
| --- | --- |
| “这一张用 85mm” | 记录为当前镜头选择 |
| “整组都用这个镜头系列” | 记录为系列共同设定，具体焦段按镜头需要处理 |
| “后面的每张都固定 50mm” | 后续镜头保留焦段锁定 |
| “只把这一张背景变清楚一点” | 更新这张的景深及有依赖的开放项 |
| “这个项目整体换成数字质感” | 更新项目范围的介质或表面表现，并保留其他有效要求 |
| “另开一个新项目” | 根据新项目输入建立其场景与摄影记录 |

多轮修改会累计保留用户指令和已经接受的变化。你先改人物位置，再改背景虚化，当前有效方案会包含这两次调整。正在使用且尚未回评的候选仍可继续修改，并保留其候选状态。

直接修复首张失败图时，使用你指定或当前实际待修改的图作为底图。此前已接受的特征作为保留要求。只有文字时，从当前有效场景与摄影候选继续修订。

## 普通文本与 JSON 怎么选

直接生成图片用的提示词默认采用普通文本。你可以要求只给提示词，也可以要求附上选型说明、参数表或来源。

需要对接工作流、保存结构化场景或交给程序读取时，可以主动要求 JSON。已有字段结构可以直接提供，造梦师按该结构输出当前有效场景。需要新结构时，可以使用精简的摄影字段。

文本与 JSON 共用当前场景和摄影选择。你切换交付形式后，人物、动作、空间、光源与已经确定的参数继续从这份记录导出。

## 与原有造梦师能力一起使用

### 剧本到画面

先依据提供的故事确定当前动作、人物关系和画面用途，再设计观看方式。给导演讨论的美术概念、承载一个叙事瞬间的关键帧和最终提示词，按你要求的阶段交付。摄影设定进入相应画面的场景记录。

### 导演方法

你点名导演、需要导演比较或推荐时，造梦师会结合现有导演体系选择观看位置、光线、色彩、空间与人物调度。明确指定的摄影器材与参数继续参与约束。电影摄影卡可提供相关资料，导演方法会落实到当前场景的具体决定。

### 解梦与风格参考

上传参考图时，可以分别指定身份、服装、构图、光线、材质或风格职责。解梦分析提取对应的可见规则，摄影设计据此解决开放的机位与成像选择。你指定的场景事实与参考职责具有优先级。

绘画、插画、版画等参考按其媒介处理。希望改成写实摄影时，可以明确提出“保留构图和色彩，改成真人电影摄影”。实物木偶、黏土和微缩定格本身可使用真实摄影器材，并保留其材质与尺度；数字模拟的定格风格按实际参考媒介处理。

### 连续镜头与资产

连续镜头可以共享摄影机、镜头系列、成像介质与整体色彩，再按每一镜的动作和空间决定景别、焦段与焦点。你明确锁定的共同参数在后续镜头中继续使用。

身份、服装、道具和场景参考资产优先把关键外观与结构交代清楚。最终镜头需要的强旋焦、低照度或眩光，按该镜头的用途应用。你可以要求先准备后续拍摄所需的素材，再继续建立镜头。

### 项目交接

需要在新对话继续时，可以要求“整理项目交接卡”。卡片记录当前有效场景、模型、已锁定摄影项、当前使用的开放候选及其接受状态、参考职责、有效修改与下一步。新对话中提供这份文字和仍需使用的参考图片，即可恢复有依据的项目状态。

### 跨模型转码

同一场景可以编译给 GPT Image、Midjourney、Seedream 或 Nano Banana 等目标模型。切换时保留人物、动作、空间、光源、机位及当前有效摄影选择，包括正在使用的开放候选，按目标模型调整文字组织与可用控制。各版独立使用同一场景输入，适合共用的自然语言可以保持一致。

你可以说“把这版转成 Nano Banana，保留 58mm、眼睛对焦和轻微旋焦”。生成后若需要进一步修复，可以提供实际图像，并指出这次希望调整的部分。

## Seedream 5.5 与 5.0 Pro

v2.7.0 加入 Seedream 5.5 独立适配器，同时保留 Seedream 5.0 Pro 的明确版本兼容。已经在对话中确定的版本继续使用。新请求只写 Seedream 或即梦且尚无版本约定时，默认使用 5.5。你可以随时明确指定 5.0 Pro。

5.5 的提示词按自然语言组织主体、空间、机位、光线、材料与保留要求。多参考图分别标明职责，多轮编辑依据当前有效输入累计调整。透明图、图层拆分和文字相关能力按用户任务与前端实际提供的功能使用。

模型页、发布文章与教程来源列在[Seedream 5.5 适配器](../zy-cinematic-realism/references/models/seedream-5-5.md)。实际生成表现需要对应成图和使用条件来判断。

## 可以直接复制的请求

以下内容是使用请求示例。按你的实际人物、场景、模型和参考替换即可。

### 自动完成摄影选择

```text
请使用 $zy-cinematic-realism，为 Seedream 5.5 写一个横向16:9的树林人物中近景提示词。白天，人物看向镜头，眼睛清楚，背景有轻微旋焦。摄影方案由你决定，直接给普通文本提示词。
```

### 用口语说明环境清晰度

```text
用造梦师写一张街边人物的画面。人物站在老店门口，我想像站在他身边看他，同时能看清后面的招牌和门面。请你选择合适的摄影设置，直接出词。
```

### 指定专业器材

```text
请使用 $zy-cinematic-realism。摄影机用 Alexa 35，镜头用 Cooke S4/i 50mm，T2.8，室内双人对话。两个人眼睛都要清楚，窗户日光是主光。其余机位和站位由你安排，写成 Seedream 5.5 的普通文本提示词。
```

### 查看器材方向

```text
我想拍有距离感的城市人物，请从造梦师器材武器库里给我几个相关镜头方向。用容易理解的话说明机位距离、背景尺度和焦外的差异，并附上来源。
```

### 查询电影摄影资料

```text
请帮我查一部我指定的电影中使用过的摄影机和镜头，并解释资料覆盖的范围。接下来我会给你具体段落或剧照，再一起决定当前场景可以借用什么。
```

使用上一项时，把影片名称、年份和你关注的段落一起提供，能更快定位资料。

### 结合导演方法与参数

```text
用造梦师为这个室内等待场景选择合适的导演方法，并说明观看位置、光线和人物调度。保留我指定的50mm镜头和窗边自然光，其他开放选择由你完成。
```

### 从参考图迁移摄影规则

```text
请用造梦师解梦这张参考图，只借用构图、清晰关系和自然光。人物身份用我的另一张人物参考，场景改为我描述的树林。按这些职责写成 Seedream 5.5 的普通文本提示词。
```

### 继续修改当前镜头

```text
在最近这版基础上，把背景再清楚一点。继续保留已经改好的站位、服装、时间和光源。只解释确实需要联动的参数，然后给更新后的提示词。
```

### 建立系列共同设定

```text
把这组镜头的摄影机、镜头系列、介质和色彩设为项目共同选择。每一镜的焦段、机位和对焦按当前动作决定。请给我三镜的普通文本提示词，并标明各镜的变化。
```

### 准备资产与交接

```text
这张人物已经确定，请先整理后续反打需要的人物与服装参考资产。然后生成一份项目交接卡，写清已接受的摄影选择、参考职责、累计修改和下一步。
```

### 按指定结构输出 JSON

```text
把当前有效场景导出为 JSON，沿用我提供的字段结构。摄影选择使用最近这版已经确定的内容，来源说明放在 JSON 外面。
```
