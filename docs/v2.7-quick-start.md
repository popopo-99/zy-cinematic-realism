# 造梦师 v2.7.0 · 一句话开始

先按[正式版指南](getting-started.md)安装完整 Skill，再在对话中使用 `$zy-cinematic-realism`。

## 先说你希望看见什么

安装完成后，直接输入：

```text
请使用 $zy-cinematic-realism：
白天树林里的人像，眼睛清楚，背景也能认出树，21:9。
器材你决定，直接给我 Seedream 5.5 普通提示词。
```

你可以说“背景别太虚”“让人物显得离我近一点”“前面虚一点，后面那个人清楚”。造梦师会把观看目标转成构图、距离、焦点和清晰范围，补齐需要的选择。拿到完整提示词后，在你选择的图像模型或应用里生成。

## 需要器材和电影方法时再深入

专业摄影武器库是v2.7升级主线。你既可以继续用口语，也可以直接给专业参数。

```text
Sony α7 IV全画幅、35mm、f/8、眼高。
门廊里的人物和后方门窗都要可读。保留这些参数，给我Seedream 5.5提示词。
```

想选型或查方法，可以问：

```text
保持人物占比时，35mm和85mm分别需要怎样的距离？空间感会怎样变？
```

或：

```text
查一下《1917》德军地下空间的摄影方法，说明已知器材和仍未知的参数。
```

[53项摄影语言](../zy-cinematic-realism/references/camera-language-dictionary.md) → [器材武器库](../zy-cinematic-realism/references/equipment-library.md) → [电影与镜头方法](../zy-cinematic-realism/references/cinema-shot-library.md)按需查询。摄影意图、设备事实、影片使用记录和实际生成效果各按其证据表达。静帧可以展示一个焦点状态，持续拉焦或运镜需要时间序列。

[雪地西部片选型实录](v2.7-camera-arsenal-snow-western.md)收录了一句口语需求、ARRI 原厂资料和实际返回的摄影方案。

## 有参考图，先说它负责什么

```text
这张图只负责画风，提取造型、明暗、材质和色彩规则。
新内容是古老观测台内调校黄铜星盘的白发男性天文学家。
不带入原人物、衣服和背景，直接给Seedream 5.5提示词。
```

要同一张脸就说明“角色身份参考”；只借颜色就说明“只参考色彩”。同一图片可以承担多个明确职责。动画、CG和插画按各自的视觉语言表达，摄影术语在有用途时参与相应观看或虚拟摄影设计。

## 按当前需要索要输出

通常直接得到普通文本。上面的自然语言请求可以很短，编译后的最终提示词会把已确定的画面意图写完整。[天文台案例的A组原始长提示词](examples/v2.7-style-output/A_Quick_Prompt.txt)展示的是最终输出。

想先审阅方案时说：

```text
先给我一个简短Plan，写清摄影、画风和参考职责。我确认后再出词。
```

想要可检查、可保存的完整结构时说：

```text
沿用同一方案，输出完整Jury JSON Brief和HEX设计色板，说明颜色职责。
人物、构图、光线和材质意图沿用当前决定。
```

Plan由你按需提出。直接出词或直接要JSON的请求可以进入相应编译。HEX是颜色设计锚点，未经采样时会标明近似值。现有单张案例尚未建立JSON + HEX的画质优势。[查看真实A/B案例](v2.7-style-output-case.md)

## 回图后只改你需要的部分

上传实际结果，再说：

```text
人物和构图已经合适，只让后面的店铺更清楚，保留原光线。
```

同一对话沿用已有选择。新对话需要延续时，附上已确认的解梦卡或风格胶囊、必要参考图和要保留的部分。
